# 连续接触RX实验参数

本目录保存可复现参数，不是实物标定值。放宽配置已有一次完整通过记录，合并几何仍须单独验收。

| 文件 | 用途 |
| --- | --- |
| `mechanical-rx-strict.json` | 接触阻抗0.99、被动定位幅值0.08牛米，其余采用程序默认值 |
| `mechanical-rx-relaxed.json` | 相同接触参数，过程位置2毫米、角度5°、核心位移2毫米，关闭自动重夹 |
| `mechanical-rx-merged.json` | 放宽过程容差，并合并共面的卡脚楔体；保留16个圆周分段，属于提速候选 |
| `mechanical-rx-1ms-experimental.json` | 失败实验：1毫秒步长虽通过 `U F2`，但同状态R动作失稳；仅用于复现，不采用 |

读取色块及最终验收保持严格标准；生成的报告会记录全部实际参数。
运行入口见[完整二十步实验](../../../docs/mechanical-rx.md#完整二十步实验)。
