# 连续接触RX实验参数

本目录保存可复现参数。它们不是实物标定值，也不表示完整还原已通过。

| 文件 | 用途 |
| --- | --- |
| `mechanical-rx-strict.json` | 接触阻抗0.99、被动定位幅值0.08牛米，其余采用程序默认值 |
| `mechanical-rx-relaxed.json` | 相同接触参数，过程位置2毫米、角度5°、核心位移2毫米，关闭自动重夹 |

读取色块及最终验收保持严格标准；生成的报告会记录全部实际参数。
运行入口见[完整二十步实验](../../../docs/mechanical-rx.md#完整二十步实验)。
