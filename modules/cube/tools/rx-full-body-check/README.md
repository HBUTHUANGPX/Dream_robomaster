# RX 全身离线扫掠检查

此工具读取完整 MJCF 场景和 `assets/rx_full_body/reachability.json`。
源码和候选均持久化，不依赖缓存中的旧探针或旧场景。
生成场景、编译和运行命令见[资产说明](../../../../assets/rx_full_body/README.md#复现完整场景检查)。

## 输入与退出码

命令格式为 `check 场景.xml 候选.json 结果.json`。
结果文件的父目录必须存在。
三个路径均由命令行传入，工具不搜索默认场景或默认候选。

当前只支持已验证的 A 右臂负 90°、B 左臂正 90°候选，腰 yaw 为零。
工具从候选读取基座、腰姿态、初始关节位置和目标工具位置、四元数。
模型需包含原机身和命名为 `A_r_*`、`B_l_*` 的真实夹爪。
工具保留模型自身的碰撞掩码和排除对，不自动关闭碰撞。

退出码 0 表示采样中未发现超过 10 μm 的机器人内部穿透，且工具位置误差小于 1 μm、角度误差小于 10 μrad、关节不越限。
退出码 1 表示输入、加载、输出或逆运动学求解失败。
退出码 2 表示检查完成但未通过。
结果 JSON 包含每个采样姿态的碰撞对和两臂逐度关节路径。

## 来源与边界

`kinematics.hpp` 来自本任务的离线运动学探针，只保留 FK、连续分支 IK 和原始 URDF 几何。
手臂尺寸、关节轴和范围来自 `assets/rx_full_body/urdf/rx_assy_v2_runtime_baseline.urdf`。
夹爪安装保持原腕末端的固定变换。
它不搜索新姿态，也不增加关节。
手动 FK 的结果用输入 MuJoCo 场景中的真实夹爪根位姿逐点复核。

`gripper-poses.cpp` 摘自 `modules/cube/src/rx_gripper.cpp` 的闭环初始化公式。
离线副本将固定电机开位扩展为参数，便于检查开闭端点及中间位置。
其余连杆几何、二分求解和球关节姿态计算保持原公式。
该文件不依赖生产程序的链接库；生产夹爪几何改变后，需同步核对本副本并重新验证。

工具检查 872 个静态姿态，单手每步 1°，对侧腕保持零位。
不调用 `mj_step`，不模拟控制器、摩擦保持或重抓动力学。
与魔方等场景物体的穿透另行记录，不纳入机器人内部避障通过条件。
两手同时转动和采样间的连续碰撞不在通过结论内。
完整物理结果应查看资产目录下的独立动态验收记录。
