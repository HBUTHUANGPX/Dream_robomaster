# PID、DWA 与 LIO 优化计划

> **历史记录，不用于当前启动。** 首次使用请阅读[根目录说明](../../../README.md)和[入门说明](../../../docs/getting-started.md)。
> 本文的“当前”“已完成”和验收数据均指记录时的 Python 版本。命令以仓库内的 `legacy/python` 为工作目录。先按[归档环境说明](../README.md)准备依赖。`output/` 中的记录是本机历史产物，不保证随仓库提供。

用户要求：用 PID 跟踪局部轨迹。尝试 DWA。评估开源 LIO。

1. 保留 CAD 地形、A*、雷达及现有定位模式。增加独立 PID 和 DWA 模块。
2. DWA 从实测轮速/陀螺仪速度构建动态窗口。采样前进和转向速度。检查地形、点云障碍及制动尾段。用路径距离、目标进展、方向和间隙评分。坡道不横移。
3. PID 用上一周期局部轨迹的当前参考位姿计算纵向和方向误差。加入限幅、抗积分饱和及导数滤波。修正指令必须再通过 DWA 约束检查。
4. 故障、停车、新目标和重置清空 PID 状态。界面报告 DWA 候选数和控制器类型。
5. 调研 FAST-LIO2、Point-LIO 的官方源码。确认 MID360、逐点时间、IMU、外参及依赖。按证据说明已运行与尚未接入的边界。
6. 先写控制单元测试，再跑原导航测试、七类真实轮驱动目标及障碍场景。保存测试结果及新版演示视频。

验收：目标可达。无物理警告。PID 输出有限且无积分累积失控。DWA 常规输出满足加速度窗口。危险状态停车。不把旧 ICP 宣称为 LIO。
