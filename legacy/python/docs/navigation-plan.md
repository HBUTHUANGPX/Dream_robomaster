# RMUC 2023 点选导航实施计划

> **历史记录，不用于当前启动。** 首次使用请阅读[根目录说明](../../../README.md)和[入门说明](../../../docs/getting-started.md)。
> 本文的“当前”“已完成”和验收数据均指记录时的 Python 版本。命令以仓库内的 `legacy/python` 为工作目录。先按[归档环境说明](../README.md)准备依赖。`output/` 中的记录是本机历史产物，不保证随仓库提供。

输入：HBUTHUANGPX/Hbut_LC_sentry 的原始 STL。保留比例、地形和出处。目标：MuJoCo 物理机器人在可达地面/坡道/高地间导航，网页点选目标，显示全局、局部、估计轨迹与激光点云。

实现：
1. 原始场景用于视觉与雷达。逐三角形薄棱柱碰撞保留凹地形，禁止整场凸包碰撞。建立带高度与净空的地形栅格。
2. 基于官方参数设计两颗固定 MID-360，一正一倒。仿真降采样射线及 IMU/轮速输入。外参固定。重建导航版底盘，必要时提高离地间隙与坡道接触能力，不覆盖原始平地模型。
3. 已知 CAD 地形先验用于全局可通行性。在线点云配准估计位置并积累实测点图。明确这是先验辅助的轻量激光建图定位，不冒充未知环境探索或 FAST-LIO。
4. 高度感知 A*、机器人半径膨胀、坡度/台阶/净空检查。局部滚动轨迹、跟踪与失效停车。用户点选不可达坐标须明确拒绝，不能伪造到达。
5. 本地网页：俯瞰点选、实时三维跟随、全局/局部轨迹、雷达点云、状态与重置。
6. 验证地图孔隙/高地连接、估计器无真值输入、实际轮驱动爬坡、跨区导航及 窗口与接口。

范围：可达性取决于底盘尺寸与爬坡极限。不能保证跨越悬崖、实体障碍、断开的高台。会用自动遍历验证图连通性，并用物理路径测试代表性的坡道和高地。不能把图连通性等同于所有路径物理验证。
