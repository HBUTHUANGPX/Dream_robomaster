# 实施与验收计划

> **历史记录，不用于当前启动。** 首次使用请阅读[根目录说明](../../../README.md)和[入门说明](../../../docs/getting-started.md)。
> 本文的“当前”“已完成”和验收数据均指记录时的 Python 版本。命令以仓库内的 `legacy/python` 为工作目录。先按[归档环境说明](../README.md)准备依赖。`output/` 中的记录是本机历史产物，不保证随仓库提供。

目标：提供可直接运行的 MuJoCo 四麦克纳姆轮步兵底盘原型，四面官方小装甲，不实现发射、裁判电子或完整比赛。

1. 官方资料：保存 2026 制作规范 V2.0.0、比赛规则 V2.2.0、AM02 说明书和官方 STEP，以及下载来源和 SHA256。
2. CAD：使用可选 cadquery 环境转换 STEP 为米制三角网格，记录坐标变换。碰撞与惯量独立简化。
3. 模型：自由底盘、四个电机轮轴、每轮被动 45° 滚子，四面固定装甲及 A 型支撑架、低位保险杠。只通过轮轴驱动运动。
4. 控制：车体速度到轮速的运动学映射、窗口 键盘和无窗口演示、截图。
5. 验收：加载、静止稳定性、正反向前进/横移/旋转、姿态与数值稳定。检查装甲方向、倾角、安装高度。保存结果与预览。

选择显式被动滚子而非底盘施力或平面运动约束，便于后续接触仿真。滚子用椭球近似，轮胎材料/惯量为设计假设，不是已标定实车参数。官方 STEP 网格仅用于可视化，CAD 依赖不属于运行必需项。
