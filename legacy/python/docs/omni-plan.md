# 全向导航与功率约束

> **历史记录，不用于当前启动。** 首次使用请阅读[根目录说明](../../../README.md)和[入门说明](../../../docs/getting-started.md)。
> 本文的“当前”“已完成”和验收数据均指记录时的 Python 版本。命令以仓库内的 `legacy/python` 为工作目录。先按[归档环境说明](../README.md)准备依赖。`output/` 中的记录是本机历史产物，不保证随仓库提供。

目标：车头不必对准路径。可侧移、后退和边走边转。提高巡航速度。限制轮端功率。

1. 纵向、横向和偏航三路 PID，移除侧向误差转朝向的耦合。
2. 三维速度窗口 DWA，圆形速度/加速度约束，保留地形、障碍、制动与边界余量检查。
3. 四轮雅可比约束：35 rad/s、10 Nm。默认 120 W 电功率估计预算。正向机械功率/效率 + 力矩平方损耗 + 转速平方损耗。系数为可配置仿真假设。
4. 规划中估算加速、爬坡及方向相关滚动阻力。1 kHz 执行中按四个速度执行器的力矩请求分配功率。
5. 页面增加独立 偏航 速度和功率显示，保留 Mac 端口转发支持。
6. 单元测试侧移、后退、平移+旋转、功率约束。七类物理目标和斜向行驶复测。与上版时间对比。录制新视频。

起始上限：平地 1.2 m/s，坡道 0.55 m/s。通过真实 MuJoCo 闭环测试后再确定最终值。默认 偏航 速度为零，没有强制朝向目标。

完成：三轴 DWA/PID、功率模型、打滑定位修正、行进中的牵引方向调整、网页控制、七目标验收和 1 倍速视频。详情见 [控制优化说明](controller-optimization.md)。
