# 仅靠摩擦抓握的修订计划

> **历史记录，不用于当前启动。** 首次使用请阅读[根目录说明](../../../README.md)和[入门说明](../../../docs/getting-started.md)。
> 本文的“当前”“已完成”和验收数据均指记录时的 Python 版本。命令以仓库内的 `legacy/python` 为工作目录。先按[归档环境说明](../README.md)准备依赖。`output/` 中的记录是本机历史产物，不保证随仓库提供。

从生成模型中移除全部夹爪与魔方之间的等式约束。抓握和释放只作为由接触确认的控制器状态。保留手指与腕部执行器、固定支座、安全张开后的腕部复位，以及独立的动作序列优化器。魔方内部约束继续近似自身关节，不承担夹爪抓握作用。

验证单面转动、整块旋转、重复交接和完整求解。增加去除摩擦和去除腕部力矩的对照，确认这些条件会阻止任务完成。检查生成模型，排除隐藏的抓握约束。

重复交接出现漂移时，先诊断实际接触柔顺性和滑移，再调整接触模型。录制新视频，并标明实验版本。导出物理检查记录，同时保留早期结果。
