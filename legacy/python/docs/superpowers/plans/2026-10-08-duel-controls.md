# 网页操作、运动与射击反馈修正

> **历史记录，不用于当前启动。** 首次使用请阅读[根目录说明](../../../../../README.md)和[入门说明](../../../../../docs/getting-started.md)。
> 本文的“当前”“已完成”和验收数据均指记录时的 Python 版本。命令以仓库内的 `legacy/python` 为工作目录。先按[归档环境说明](../../../README.md)准备依赖。`output/` 中的记录是本机历史产物，不保证随仓库提供。

用户明确要求直接修正现有流程。实现保留 RGB 识别和本车测量，不引入敌方真值。过程采用代码质量、系统调试和验证流程。

## 修改范围

- 数字纹理：逐像素测试确认正面上下翻转，纠正此前肉眼近拍的判断。翻转正面纹理纵坐标。背面原先共用纹理坐标，导致镜像，现改用素材黑边。八块装甲外侧均与原素材逐像素比较。
- 网页：将脚本放入独立 `app.js`。使用实体键码。防止上次点击的按钮劫持空格。松键立即刹停。禁止原生图像拖动。将指令串行化，并合并连续指令。用待提交状态和修订号阻止旧轮询覆盖设置。明确显示暂停状态、回中按钮和停车按钮。
- 运动：移速范围为 0～4 m/s，转速范围为 0～4 rad/s，两者默认值均为 2。默认运动模式仍为静止。轮速上限随范围调整，不在 35 rad/s 静默截断。保留边界制动。
- 无敌：默认开启。双方命中计数，但不扣血或判胜。关闭后使用 200 HP 规则。热量规则继续生效。界面显示等待原因和剩余秒数。
- 开火：图像频率保留 20 Hz，控制与射击检查提升至 100 Hz。保留原始 ONNX。持续预测未来装甲，并使用选择迟滞和速度前馈。按装甲投影尺寸判断窗口，显示热量、射频、观测和对准阻塞原因。
- 同济参考：固定 `sp_vision_25` 提交 `bd9f5e798fa3c6dd3b483ae6627796afb41c608d`。阅读识别、解算、11 维滤波、规划和开火代码，并记录适配与未移植部分。

回归覆盖按键虚拟机行为、真实渲染方向、速度设置、无敌、首发时间、100 Hz 射频，以及正常和高速场景。完成独立代码审查和全套 pytest。重启 8766 服务，并校验 `localhost:54232` 转发请求。没有浏览器时，不宣称完成端到端验证。

审查后加入 `pauseIntent` 与修订号同步。连续指令排空后才允许回中或重置。切回自瞄时，搜索起点使用当前实测云台角。六项 Node 行为测试通过。
