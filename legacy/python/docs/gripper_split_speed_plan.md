# 腕部 8 倍与夹爪 32 倍摩擦抓握实验

> **历史记录，不用于当前启动。** 首次使用请阅读[根目录说明](../../../README.md)和[入门说明](../../../docs/getting-started.md)。
> 本文的“当前”“已完成”和验收数据均指记录时的 Python 版本。命令以仓库内的 `legacy/python` 为工作目录。先按[归档环境说明](../README.md)准备依赖。`output/` 中的记录是本机历史产物，不保证随仓库提供。

## 目标与实现

腕部和夹爪倍率分别设置。腕部沿用原五次轨迹，并按 8 倍速度执行。90° 转动时长为 0.10625 s，按物理步舍入后为 0.1062 s。180° 转动时长为 0.15 s。

夹爪参考时长为 `0.30/32=0.009375 s`，舍入后为 0.0094 s。这些是轨迹时长，不是视频播放倍速。

实验使用原有 Robotiq 几何，并将其修改为高性能平行手指配置。该配置不代表原厂 Robotiq 的额定性能。

- 手指折算电机惯量 `armature` 降为原值的 1/100。刚体质量和惯量张量保持不变。
- 内部关节约束将自适应连杆角度保持为零，使手指在加速时保持平行。夹爪与魔方之间仍没有焊接或连接约束。
- 手指伺服为 `Kp=102400`、`Kv=320`。0～255 输入仍按 `0.8/255 rad` 换算。自由运动的广义力矩限制为 ±40 N·m，在接触或闭合轨迹结束时降至 ±5 N·m。该数值是执行器广义力矩，不是以牛顿计的指尖力。
- 闭合先平滑趋近 0.332 rad 驱动角，再保持在受力矩限制的 0.345 rad 参考角。张开目标为 0 rad。动作计划中的 `jaw=115` 表示请求闭合抓握，不再直接充当高速电机设定值。
- 轨迹初始位置取自实测执行器长度，避免从带载保持指令跳变。
- 物理步长为 0.1 ms。魔方内部约束、连杆约束和指尖接触的时间常数为 0.3 ms。摩擦阻抗比为 100。滑动与扭转摩擦系数仍为 1.2 和 0.005。没有抓握粘合约束或外加刚体力。
- 实际张开间隙或双侧接触必须连续满足 4 ms，夹爪指令才完成。检查失败就停止执行。抓握确认仍要求双侧存在正接触力。

原始 1 倍配置和早期统一 `--speed` 实验继续保留。只有显式设置 `--jaw-speed > 1` 才启用修改后的手指配置。

## 验证与时序

完整 20 步打乱使用 434 个优化动作完成还原。腕部为 8 倍，夹爪为 32 倍。录制前的成功无窗口执行用时 31.3366 s。

六面集成探查测得，达到安全张开或双侧接触需要 8.9～11.7 ms，之后另加 4 ms 确认。录制结果与各次实际运动分别导出到 `verification.json`。

缩短腕部和层转动后的稳定等待曾导致后续接触确认失败。因此，验证版本保留 150 ms 的腕部与层稳定等待。总求解时间不能简单除以 8 或 32，也不能通过取消接触和对齐检查来缩短时间。

## 历史复现

先按归档环境说明安装 `cube` 依赖组。录制还需要可用的 EGL、FFmpeg 和 Noto CJK 字体。

```bash
MUJOCO_GL=egl uv run --group cube python record_dual_gripper_cube.py \
  --wrist-speed 8 --jaw-speed 32 --playback 1 \
  --output output/dual_gripper_wrist8_jaw32
```

`controller_profile.json` 记录执行器参数、步长和播放速度。`verification.json` 记录物理还原、轨迹测量和碰撞检查。`plan.json`、`plan_unoptimized.json` 和 `steps.csv` 保留独立的编译与优化结果。视频使用 1 倍播放，并包含短暂的开始与结束停留。

## 最终录制结果

实时录制中的执行时长为 31.3397 s。包含首尾停留的视频为 35.867 s，共 1076 帧，帧率为 30 帧/s，编码为 H.264，分辨率为 1280×720。视频通过完整 FFmpeg 解码。

59 次张开在 8.9～9.5 ms 达到安全间隙。包含 4 ms 确认的指令完成时长为 12.8～13.4 ms。

61 次闭合包含初始化抓握。首次双侧接触在 8.8～9.9 ms 出现，连续接触最迟从 12.7 ms 开始。指令完成时长为 12.7～16.6 ms。间隙变化速度峰值为 6.96～7.82 m/s。这些实测响应与 32 倍参考设置分别记录。

98 次腕部旋转的四分之一圈时长为 106.2 ms，半圈为 150 ms，随后等待 150 ms 稳定。峰值速度为 27.83～39.42 rad/s。峰值腕部力矩为 1.73 N·m，低于原有的 15 N·m 上限。

69 项相关测试通过。全部 54 个色块还原，内部面电机力为零，MuJoCo 数值警告为零。261,588 个旋转物理步没有禁触。最小张开间隙为 91.363 mm，高于要求的 89.136 mm。

高速配置还通过摩擦对照。侧向单手抓握在去除摩擦后，0.5 s 内滑移 17.094 mm。保留摩擦时滑移仅 0.000014 mm。对应本机历史产物为输出目录中的 `friction_control.json` 和 `motion_summary.json`。
