# 同济 SuperPower 2025 自瞄方案对照

> **历史记录，不用于当前启动。** 首次使用请阅读[根目录说明](../../../README.md)和[入门说明](../../../docs/getting-started.md)。
> 本文的“当前”“已完成”和验收数据均指记录时的 Python 版本。命令以仓库内的 `legacy/python` 为工作目录。先按[归档环境说明](../README.md)准备依赖。`output/` 中的记录是本机历史产物，不保证随仓库提供。

用户指定文章：[RM2025 自瞄算法开源](https://bbs.robomaster.com/article/803315?source=4)。正文浏览结果未包含主体，因此同时核对其[官方仓库](https://github.com/TongjiSuperPower/sp_vision_25)，固定提交 `bd9f5e798fa3c6dd3b483ae6627796afb41c608d`。许可证 MIT 保存在 `assets/tongji_reference/`。下面区分已适配内容和没有实现的部分。

| 环节 | 同济实现 | 本仿真处理 |
| --- | --- | --- |
| 采集与时间对齐 | 相机时间戳配合 IMU 四元数插值。`io/cboard.cpp`、`io/gimbal/gimbal.cpp` | RGB 与本车外参同一仿真时刻。未模拟异步串口、相机延迟或 IMU 噪声 |
| 识别 | 传统灯条/分类器与 YOLOv5/8/11 四点检测接口。分类器输入32×32 | 保留已有 ChenJun 原始20×28 ONNX，不能直接换成同济32×32预处理。仅识别模块读RGB |
| 位姿 | IPPE 后固定装甲倾角，搜索 偏航 以减小角点重投影误差。`solver.cpp` | 新增向外法向 ±80°、1°步长向量化搜索。使用视觉平移和已知15°安装倾角，未读取目标姿态。特征仍124×52 mm，未照搬其135×56 mm |
| 状态估计 | 11维整车 EKF，含半径差/高度差。观测为方位/俯仰/距离/装甲偏航。归一化新息平方监测 | 保留本仓库11维位置/速度/转速/双半径/高度差滤波，笛卡尔位姿观测及马氏门限。提高平移过程噪声以覆盖新增高速运动，不声称与同济观测方程相同 |
| 目标关联 | 编号/优先级、四板关联、状态机、发散与重获 | 当前一对一同号四板关联。新增从最后视线附近搜索，避免丢目标立即大范围转头。不包含多目标优先级或全向感知 |
| 轨迹与控制 | 预测飞行时间。TinyMPC约束云台加速度，输出角度/速度/加速度。切板前平滑过渡 | 图像20Hz、预测/控制100Hz。切板选择迟滞。依据MuJoCo位置伺服`kv/kp` 增加速度前馈。不含完整TinyMPC或五次轨迹优化，不声称已经达到同济规划器效果 |
| 火控 | 对比射击轨迹与规划轨迹，并考虑拨弹延迟 | 100Hz检查当前枪口对未来装甲投影窗口。角度门限改为米制横/纵窗口，保留弹丸半径裕量。仿真发射命令即时出膛，无虚构机械延迟。温度与射频继续单独约束 |
| 调试 | 模块测试、录制与曲线回放 | 增加开火阻塞原因/剩余秒数，分离移速与转速，支持无敌计分。保存高速验收首发、发射/命中、跟踪率及警告 |

下列路径相对于上述同济上游仓库，而非本地归档。阅读源码：`tasks/auto_aim/{solver,target,tracker,classifier,shooter}.cpp`、`tasks/auto_aim/planner/planner.cpp`、`readme.md` 的轨迹理论部分。关键差异是本仓库尚未做“未来多时刻轨迹在加速度约束下整体优化”。速度前馈和尺寸窗口只是当前可验证的改进。

验证入口：`scripts/validate_duel_controls.py`。它使用5秒、约4米起始距离、爆发优先、无敌模式。速度上限不等于全范围识别/射击保证。高速横移和绕圈仍会出现数字漏检、平面位姿噪声及转向估计滞后，报告原样保留这些误差。
