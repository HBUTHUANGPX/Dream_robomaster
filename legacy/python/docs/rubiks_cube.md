# MuJoCo 魔方

> **历史记录，不用于当前启动。** 首次使用请阅读[根目录说明](../../../README.md)和[入门说明](../../../docs/getting-started.md)。
> 本文的“当前”“已完成”和验收数据均指记录时的 Python 版本。命令以仓库内的 `legacy/python` 为工作目录。先按[归档环境说明](../README.md)准备依赖。`output/` 中的记录是本机历史产物，不保证随仓库提供。

## 设计与验收计划

本版在 RoboMaster 仿真旁实现独立魔方示例，采用可切换约束设计。它复用 MuJoCo、NumPy、Pillow 和系统 FFmpeg，不增加额外 Python 依赖。

- `rubiks_cube.py` 生成 MJCF，维护块体排列和朝向，在对齐边界切换焊接约束，驱动六个物理铰链，并提供命令行演示和交互窗口。
- `tests/test_rubiks_cube.py` 检查六面物理位姿、四次转动还原、不交换的跨轴动作、逆打乱还原及非法命令。检查对象是 MuJoCo 刚体位姿，而不只是逻辑状态。
- `record_rubiks_cube.py` 渲染实际仿真帧，生成展示初始还原、打乱、逆序恢复和最终验证的 MP4。
- `assets/rubiks_cube.xml` 和 `output/rubiks_cube/` 分别保存生成模型和本机历史产物。

核心固定。二十个活动块使用自由关节，六个中心块使用铰链。每个活动块预分配一条到核心和六条到中心的焊接约束，但任意时刻只启用一条。

转动开始时，将选中的八个块连接到对应中心。结束后再连接回核心。启用约束前更新焊接坐标。运动由 `mj_step` 积分，不通过改写块体 `qpos` 制作动画或恢复状态。

模型一次只允许转动一个面。电机驱动转动，控制器保证换层合法。魔方内部碰撞关闭，外部接触几何保留。这是混合刚体近似，未模拟内部轨道、容错切角或机械手。

本版恢复功能使用已知打乱的逆序，不是通用魔方求解器。该限制属于此历史版本，当前原生模块以现行模块说明为准。

交付前须验证新行为，运行已有测试，检查视频帧，并验证编码流。

## 历史运行

先按归档环境说明准备依赖。交互窗口需要桌面显示。录制需要 EGL、系统 FFmpeg 和已安装的 Noto CJK 字体。

```bash
uv run python rubiks_cube.py --viewer
uv run python rubiks_cube.py --moves "R U F' L2 D B R' U2 F D'" --restore
MUJOCO_GL=egl uv run python record_rubiks_cube.py
uv run --group dev --group cube --group lio python -m pytest -q tests
```

按 R/L/U/D/F/B 可从对应面的外侧观察方向顺时针转动。S 执行演示打乱。Z 执行全部动作历史的逆序。命令逐个执行。

`--moves` 中的单引号表示逆时针，`2` 表示半圈。生成 XML 仅包含初始锁定状态。必须通过 `RubiksCube` 加载，才能在运行时重新分配层约束。单独加载 XML 不会执行 Python 切换逻辑。因此，本版演示需要初始 MJCF 和 Python 代码。

电机以有限增益跟踪平滑指令。转动中，实际铰链角可能落后于指令。控制器先等待终点稳定，再重新分配层。

在对齐边界，核心焊接目标设置为精确离散位姿，由求解器消除残差。程序不重置块体 `qpos`。其他中心铰链由位置伺服保持。

## 录制验证记录（2026-10-08）

- MuJoCo 3.15.0 下通过 29 项测试，其中魔方测试 21 项，原有底盘测试 8 项。
- 六面转动、四次转动还原、不交换的跨轴动作、非法命令、中点圆周运动和逆打乱恢复均通过验证。
- 停用电机力后，转面会因对齐检查失败而停止，不会把块体排列更新成成功状态。
- 本机历史视频 `output/rubiks_cube/demo.mp4` 为 H.264，分辨率 1280×720，帧率 30 帧/s，共 892 帧，约 29.73 s。
- 二十个活动块的最终最大位置误差为 `1.5696e-6 m`。
- 最终最大朝向误差为 `7.885e-8 rad`，MuJoCo 警告为零。
- 每次动作和最终测量保存在 `output/rubiks_cube/verification.json`。
- 同一输出目录中的静态图为 `01_solved.png`、`02_scrambled.png` 和 `03_restored.png`。视频帧直接来自 MuJoCo，字幕由 Pillow 叠加。整段录制使用同一个仿真实例。

该次验证没有手动操作图形窗口按键，但已运行自动物理测试和完整无窗口录制。本版未实现机械手、自由漂浮核心、内部机械接触或外部任意状态的通用求解器。
