2027 官方规则页面目前提供变更前瞻。为保证依据完整，本仓库固定使用 2026 完整赛季文档，不宣称符合未来规则。

## 模块与 CAD

- [小装甲模块](https://bbs.robomaster.com/wiki/20204847/811816?source=7)：下载 AM02 2019 STEP 和网页标为 AM02&AM12 2020 的说明书。PDF 内部版本实际为 v1.0 2018.11，原样保留并明确区分。
- [A 型架](https://bbs.robomaster.com/wiki/20204847/811821?source=7)：官方资料中心提供的 2019 STEP。不是根据图片手画支架。
- AM02 说明书标称 140 × 125 mm、359 g，一个模块用两个支撑架。CAD 总包围盒含突出部分，约 19 × 141 × 129.965 mm，因此不把标称尺寸当成整体 CAD 的精确包围盒。
- STEP 经 CadQuery/OpenCASCADE 三角化为 OBJ，单位 mm 转 m。原始文件不改变。原始版权归官方，未将官方资产重新许可为本仓库原创资产。

装甲 native +X 为正面、+Y 为上、-Z 为左。转换为局部 X 向外、Y 向左、Z 向上，中心取 `(-17.40697118333, 63.89617963739, -45.00439550208)` mm，再向后倾 15°。

支架 native X 为横向，native +Z 为装甲接合面法线。转换矩阵见 `scripts/convert_cad.py`。底部平面法向经旋转变为竖直。支架安装平台定位依据 CAD 底面而非包围盒最低点：平台顶面在装甲组件原点下方 31.868407 mm。螺孔 X 坐标约 -19.894086、-44.894086 mm。平台和支撑臂是简化自设计件。装配为刚体近似，未模拟卡扣、紧固件预紧力及 60 N 刚度试验。

## 轮地接触与控制

四个轮轴沿车体 +Y，四电机采用带扭矩限幅的速度执行器。轮毂只可视化，48 个滚子参与轮地接触。每个滚子一个被动转轴，轴向与轮轴夹角 45°。前左/后右与前右/后左滚子方向相反，形成 X 型排列。

设 `a=b=0.18 m`，`r=0.076 m`，轮序 FL、FR、RL、RR：

```text
ω = [vx - vy - (a+b)wz,
     vx + vy + (a+b)wz,
     vx + vy - (a+b)wz,
     vx - vy + (a+b)wz] / r
```

逆运动学只产生轮速目标。底盘的位置、姿态、速度由 MuJoCo 接触动力学积分。无 `qpos` 强制更新、无平移执行器、无底盘外力补偿。碰撞掩码 允许机器人与场地接触，禁用内部自碰撞以减少滚子互穿近似造成的非物理干扰。新增障碍物应设 `contype=1, conaffinity=2`。装甲使用透明盒体碰撞代理，CAD 只可视化，不模拟受击传感器。

该近似适合平地运动与控制入门。椭球滚子并非加工级滚子曲面，复杂地形、轮胎弹性、轮轴负载和功耗尚未验证。模型无悬挂、云台及完整赛事装置。
