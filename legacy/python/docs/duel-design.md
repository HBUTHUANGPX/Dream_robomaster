# 一对一 图像自瞄设计

> **历史记录，不用于当前启动。** 首次使用请阅读[根目录说明](../../../README.md)和[入门说明](../../../docs/getting-started.md)。
> 本文的“当前”“已完成”和验收数据均指记录时的 Python 版本。命令以仓库内的 `legacy/python` 为工作目录。先按[归档环境说明](../README.md)准备依赖。`output/` 中的记录是本机历史产物，不保证随仓库提供。

用户已确认真实渲染 RGB → CV 灯条检测/装甲配对 → PnP → 云台角度及自身位姿 → 卡尔曼预测 → 云台/弹道控制，并授权开始实现。

复用 `assets/robot.xml` 的物理麦轮和官方 AM02 网格，独立生成双车场景、两轴云台与相机。图像 800×600、垂直视场 45°。CV 使用本模型灯条中心距 124 mm、长度 52 mm（这是现有模型的特征几何，不是把装甲外壳或官方通用 PnP 尺寸混为一谈）。相机采用无畸变针孔模型，位置、朝向由本车底盘位姿、云台编码器和固定外参组成。本车位姿首版使用理想里程计。不含实车 SLAM 噪声。

视觉模块不能引用 MuJoCo 或敌方真值。跟踪器接收带时间戳的 PnP 相机位置及相机外参，用位置/速度状态、非线性角度距离观测的 EKF 融合连续图像观测。异常值门限、短时预测、失联停火、重新捕获。不接雷达。PnP 有远距离及正视平面歧义，须展示重投影误差与置信状态，不宣称是实车标定结果。

弹丸为直径 17 mm、质量 3.2 g 的球，世界初速包含枪口速度，重力 9.81 m/s²。首版无空气阻力，弹丸做独立解析推进和每物理步的扫掠碰撞，与 MuJoCo 机器人接触动力学分开。装甲正面、法向速度 >12 m/s、同装甲 50 ms 间隔才扣 20 HP。地面、车体和场地边界吸收弹丸。固定简化 一对一 场地和 200 HP，不模拟完整比赛经济/等级/功率体系。

2026 V2.2.0：初速上限 25 m/s。每发热量 +10。冷却每 100 ms 结算。一级冷却优先 Q0=40、12/s。一级爆发优先 Q0=170、5/s。超 Q0 锁枪和第一视角直到热量归零。达到 Q0+100 永久锁枪（正文 > 与流程图 ≥ 不一致，采用流程图保守边界并注明）。默认开启预防超热的发射调度。可关闭以验证规则。

网页：中文操作说明、红蓝血量、可切换俯视/跟随画面和原始/标注相机画面。键盘按住移动、松开停止、失焦停止，鼠标/方向键云台。自瞄/自动开火/敌方反击开关。静止、横移、绕圈、自转目标。热量/弹速/射频。暂停/重置。检测、预测、命中率与日志。默认不自动开火，点击开启。服务只监听本机，命令在仿真线程执行。

验收：图像检测距离与朝向变化测试。空帧无检测。滤波收敛及失联停止。静止和横移命中。热量边界和恢复。非法 HTTP 输入。现有回归测试。保存截图与 JSON 验证记录。
