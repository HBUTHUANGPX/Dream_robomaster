运行入口与条件见 [模块说明](../../../docs/modules/cube.md#rx-全身原机关节实验)。

场景只使用29个原机关节执行器和2个夹爪电机；不添加腕轴。
初始装载约束在夹紧后释放一次；后续靠摩擦夹持和原关节执行。

| 用例 | 物理还原 | 执行时间 | 最终块体位置误差 | 本机计算时间 |

| R → R′ | 通过 | 27.162秒 | 0.265毫米 | 105.112秒 |
| U → U′ | 通过 | 39.943秒 | 0.258毫米 | 155.433秒 |

R 用例覆盖右臂转层、松爪回位和重新夹持。
U 用例额外覆盖两臂换手、整块转动、左臂转层。
录像均为1倍速，末尾额外保留0.5秒观察帧。
原始报告、视频和最终画面分别为同名前缀的 `.json`、`.mp4` 和 `.png`。
历史报告的 `wrist_motions.actuator` 字段使用逻辑轴名 `A_yaw_drive` 或 `B_yaw_drive`。
该名称不代表模型含有额外执行器；`native_arm_execution=true`、`full_body.added_wrist_joints=0` 标明原生手臂执行。
当前代码已将该字段改为 `logical_axis`，以免与真实执行器混淆。

本次共享工作区的 `./rm test` 通过47项 C++、19项 Rust、36项网页与入口测试，文档检查通过。
该计数包含同期导航工作区改动；整机提交不包含这些导航改动。
相关 C++ 复验也通过，包括全身连接和连续逆运动学、F/S电机参考表、受限动作搜索及其回放。
这不是20步长序列验收，也不是自由站立或真实硬件标定。

## 快速配置与中心补偿验证

配置为 `modules/cube/configs/mechanical-rx-full-body-fast.json`。
工具峰值速度为2 rad/s，90°动作约1.473秒，夹爪开合为0.25秒。
不添加动作间等待。指尖接触时间常数为1毫秒，物理步长为0.5毫秒。
双臂公共平移补偿使用4/s增益、1毫米幅值上限和10毫米/秒变化速度上限。
补偿使用仿真核心位置观测，经原关节执行器执行，不修改实际物体状态。

调参失败记录见 [速度试验](speed_probe_results.json)。
增大夹持力矩、启用 noslip 和增大摩擦阻抗比均未解决原始漂移。
仅降低至3 rad/s的长序列也在还原阶段触发跟踪失败。
上述失败用例不能作为成功录像或实物速度上限。

本轮中心补偿改动后的47项 C++ 测试通过。
`./rm test` 中启动器跨仓库保留测试曾失败，单项重跑和完整 Rust 重跑均通过，共19项。
该测试在检查另一仓库的双服务前，只等待其中一个服务就绪；本轮未修改启动器测试。
后续36项网页与入口测试和文档检查通过。
新增单元测试验证补偿方向、幅值上限及不修改实际 `qpos`；闭环收敛由动态验收确认。

中心补偿也有边界：公共平移目标不等于实测转层轴。
历史4 rad/s仅开启公共平移补偿的长序列在还原第15步转层时失败，双臂跟踪正常，但块体转角误差约0.089 rad。
此时补偿已达1毫米上限；继续增加补偿范围不能替代旋转中心对齐。

## 历史完整打乱与还原

使用上述快速配置，20步打乱为：

```text
R U F' L2 D B R' U2 F D' L B2 U' R2 F2 D L' U B' R
```

物理状态读出后，求解器生成20步还原；软件规划遵守原机关节可达范围。
执行时间214.198秒，末尾保留0.5秒观察帧；视频30帧/秒，共6441帧，时长214.7秒。
[完整视频](full20_fast.mp4) 仅叠加 [步骤字幕](full20_fast.srt)，不删帧、不加速。
[原始报告](full20_fast.json) 中 `passed=true`、`solved=true`，40个整步检查点全部完成。
最终块体位置误差0.240毫米，姿态误差0.00758 rad；核心位置偏移约0.0011毫米。
双臂末端对补偿目标的位置误差分别为0.113和0.086毫米。
[最终画面](full20_fast.png) 与报告、视频一同保存在仓库内。

运行条件、完整命令、预期输出及失败处理见 [模块说明](../../../docs/modules/cube.md#rx-全身原机关节实验)。
复现命令生成的 `demo.mp4` 为无步骤字幕的原始录像，播放速度同样为1倍。
当前只验收这一组完整打乱与还原；固定骨盆，不代表自由站立或实物标定。
3 rad/s开启中心补偿仍在还原第16步触发跟踪检查，相关失败数据已保留。

本轮还试验了递推式实测旋转中心参考。单步几何测试通过，但复审发现跨动作的目标累积风险。
该原型未进入交付代码；最终代码已重新构建，整机控制测试复验通过。
