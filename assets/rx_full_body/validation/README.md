# RX 全身短序列验收

日期：2026-10-15。使用 MuJoCo 3.15.0，固定骨盆。
运行入口与条件见 [模块说明](../../../docs/modules/cube.md#rx-全身原机关节实验)。
配置为 `modules/cube/configs/mechanical-rx-full-body.json`。
每次从同一个已还原魔方开始，求解结果由物理色块读出生成。
场景只使用29个原机关节执行器和2个夹爪电机；不添加腕轴。
初始装载约束在夹紧后释放一次；后续靠摩擦夹持和原关节执行。

| 用例 | 物理还原 | 执行时间 | 最终块体位置误差 | 本机计算时间 |
| --- | --- | --- | --- | --- |
| R → R′ | 通过 | 27.162秒 | 0.265毫米 | 105.112秒 |
| U → U′ | 通过 | 39.943秒 | 0.258毫米 | 155.433秒 |

R 用例覆盖右臂转层、松爪回位和重新夹持。
U 用例额外覆盖两臂换手、整块转动、左臂转层。
录像均为1倍速，末尾额外保留0.5秒观察帧。
原始报告、视频和最终画面分别为同名前缀的 `.json`、`.mp4` 和 `.png`。
历史报告的 `wrist_motions.actuator` 字段使用逻辑轴名 `A_yaw_drive` 或 `B_yaw_drive`。
该名称不代表模型含有额外执行器；`native_arm_execution=true`、`full_body.added_wrist_joints=0` 标明原生手臂执行。
当前代码已将该字段改为 `logical_axis`，以免与真实执行器混淆。

本次共享工作区的 `./rm test` 通过47项 C++、19项 Rust、36项网页与入口测试，文档检查通过。
该计数包含同期导航工作区改动；整机提交不包含这些导航改动。
相关 C++ 复验也通过，包括全身连接和连续逆运动学、F/S电机参考表、受限动作搜索及其回放。
这不是20步长序列验收，也不是自由站立或真实硬件标定。
