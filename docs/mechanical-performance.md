# 连续接触魔方性能实验

## 目标与测量边界

保留真实接触限位、自由核心和RX摩擦夹持，不切换内部约束，不在执行中重设位姿。
先比较短动作，再验证完整序列。几何扫描、单步位姿通过不等同于完整还原。

2026年10月11日基线测量：原场景2709个几何体、166个速度自由度。
从已夹持状态保持控制目标推进0.5秒，无录像计算约12.38秒。
碰撞检测约占60%，约束求解约占39%，不能仅靠关闭录像解决速度问题。
该计时不包含模型加载与图像编码，也不是完整动作的平均耗时。

## 几何合并

原卡脚每个圆周单元由两个三角楔体组成。
`cap_merge_quads:1` 仅在四点共面时合并为一个凸体，非共面单元仍保留两个三角楔体。
保留原球面采样点、内外半径和中心卡脚缺口。场景几何体由2709个降至2069个。
圆周分段另由 `cap_sectors` 控制，默认16；改变分段会改变几何近似，须重新验证。
当前候选见 `modules/cube/configs/mechanical-rx-merged.json`。

同一真实快照的R动作初筛：

| 配置 | 推进耗时 | 最大位置误差 | 最大姿态误差 | 单步位姿 |
| --- | ---: | ---: | ---: | --- |
| 原几何 | 37.51秒 | 0.2134毫米 | 0.4203° | 通过 |
| 共面合并、16分段 | 24.51秒 | 0.2135毫米 | 0.4171° | 通过 |

本次约1.53倍提速。实验期间另有仿真运行，不能视为独占机器的稳定性能保证。
从初始状态执行R打乱、读取物理状态、求解并还原也通过：仿真11.1秒，计算176.75秒。
从初始状态执行 `U F2` 打乱及求解还原也通过：仿真26.2秒、计算428.62秒，最终位置误差0.219毫米。
在 `R U` 构型下扫描F面，73个角度采样未发现内部穿透；这不是动态稳定性证明。

将圆周分段降至12也通过R还原，但本次计算213.04秒，末态接触点298个；16分段合并版末态194个。
粗化后未观察到提速，不采用该方案。该比较存在并行CPU负载影响，不能单独归因为几何数量。

## 增大步长

16分段合并版使用1毫秒步长，从初始状态完成 `U F2` 打乱及求解还原。
该流程覆盖整块换向、夹爪交接和半圈转层，最终通过严格验收。
仿真26.2秒、计算230.74秒；最终位置误差0.327毫米、姿态误差0.475°。
但从原流程同一夹持快照执行R转动时，位置误差达到33.6毫米，诊断提前停止。
该方案对初态敏感，淘汰。失败参数保存在 `modules/cube/configs/mechanical-rx-1ms-experimental.json`，仅用于复现。
这不是单纯减少运算次数：步长也会影响接触约束的数值行为，不能直接推广到其他参数。

## 减少卡脚径向分层

`cap_rings` 按中心、棱块、角块顺序设置三种卡脚的径向层数，默认 `[3,3,3]`。
每项必须是1至4的整数。圆周分段仍为16，共面合并保持开启。
该参数改变曲面近似，不能根据几何体数量直接认定物理效果等价。

2026年10月11日，使用同一原始夹持快照执行R转层，动作、步长和驱动力不变。
以下为无录像的独立诊断，耗时不包含场景加载和输出图片。

| 径向层数 | 几何体 | 碰撞耗时 | 整段计算耗时 | 最大位置误差 |
| --- | ---: | ---: | ---: | ---: |
| `[3,3,3]` 基准 | 2069 | 11.47秒 | 24.39秒 | 0.2135毫米 |
| `[2,2,2]` | 1557 | 7.95秒 | 20.98秒 | 0.2100毫米 |
| `[3,2,2]` | 1749 | 8.49秒 | 22.19秒 | 0.2132毫米 |
| `[3,3,3]` 复测 | 2069 | 11.50秒 | 24.62秒 | 0.2135毫米 |

三组单步位姿都通过，但 `[2,2,2]` 在 `R U` 构型下扫描F面时出现0.113毫米干涉。
干涉发生在中心卡脚与棱块卡脚之间，该方案淘汰。
失败配置保存在 `modules/cube/configs/mechanical-rx-two-rings-experimental.json`，仅供复现。

`[3,2,2]` 保留中心卡脚精度，减少320个几何体。
同一构型的六面扫描共438个角度采样，未检测到内部穿透。
还原态的六面扫描另有438个采样，同样未检测到内部穿透；合计876个采样。
本次碰撞耗时减少约26%，整段计算耗时减少约9%；原几何首尾复测接近。
仿真期间有其他任务运行，不能把该结果作为独占机器的固定加速比。
候选配置为 `modules/cube/configs/mechanical-rx-selective-rings-experimental.json`，尚不替换当前实验配置。
几何扫描与单步位姿不证明连续还原稳定，需要从初始状态另行验证。

该候选随后从初态完成 `U F2` 打乱及 `F2 U'` 还原，退出码0，`passed:true`、`solved:true`。
四个输入检查点齐全；打乱读取前触发一次A爪恢复。
仿真24.10秒、计算326.02秒，最终位置误差0.393毫米、姿态误差0.930°。
相对原三层同动作搜索配置的362.93秒，本次计算减少约10%；恢复发生阶段不同，不作为纯碰撞加速比。
这仍只是短流程成功，不能宣称长序列脱块问题已经解决。

针对原六步流程首次R转动脱块的快照，独立复现原几何末态位姿失败，最大位置误差1697毫米。
同一快照换用 `[3,2,2]` 后，单步末态位姿通过：位置误差0.464毫米、姿态误差0.777°。
这证明该特定失效状态得到改善，不代表完整六步通过。
后续六步流程完成打乱，但在还原F2时再次脱块，只完成9个输入检查点。
进一步结构优化见[承托环与连续曲面实验](mechanical-contact-redesign.md)。
关键快照已随Git保存，见[碰撞诊断资产](../assets/mechanical_cube/README.md)，不依赖本地输出目录。

没有删除卡脚之间或核心与角块卡脚之间的碰撞。
自由块可能相对核心偏移，单个姿态的径向间距不能证明整段执行中永不接触。

在仓库根目录，完成下方依赖准备后，以候选配置生成场景并执行短流程：

```bash
./rm cube --mechanical \
  --rx-bundle assets/rx_gripper/mujoco_linkage_v5 \
  --mechanical-config modules/cube/configs/mechanical-rx-selective-rings-experimental.json \
  --scramble "U F2" --solve \
  --output output/cube-mechanical/selective-rings-uf2-check
```

退出码0且报告的 `passed`、`solved` 均为真才通过。失败时保留最早失败报告，不自动重复运行。
使用现有[独立复现工具](mechanical-rx.md#单步故障复现)对比相同快照，读取报告中的 `timers.pos_collision` 和 `dynamics_wall_time_s`。
这些独立诊断不得拼接成连续录像。

本次实现回归通过21项C++、19项Rust和34项Node测试，文档检查通过66个文件。
增加诊断资产说明后，文档检查覆盖67个文件。
数组长度、零值、超范围、非整数和超大整数参数均被拒绝。

## 求解器对照

从同一快照保持控制目标推进0.5秒，顺序运行六次：

| 选项 | 计算耗时 | 结果 |
| --- | ---: | --- |
| 默认自动雅可比、Newton，首尾复测 | 11.85、11.84秒 | 末态一致、无警告 |
| 显式稀疏雅可比 | 11.96秒 | 与默认末态完全一致，没有提速 |
| 稠密雅可比 | 29.15秒 | 更慢 |
| 稀疏雅可比、CG | 22.10秒 | 加速度异常、自动重置，淘汰 |
| 禁用多接触碰撞检测 | 6.71秒 | 核心漂移0.546米，淘汰 |

保留默认求解器与碰撞选项。稳态短测量仅用于初筛，不代表转层、换手或完整还原表现。

## 动作路径与有限恢复

2026年10月11日，十二元动作搜索接入连续接触执行器。
原20步打乱的预计动作时间从198.2秒降至100.6秒；完整流程的计算耗时尚未验证。
省去部分回腕和开合后，`U F2` 在最终对齐阶段仍有1.325°姿态误差。
保持双爪夹紧等待2秒未消除该误差。释放A爪后，误差降至0.712°；闭合后最终为0.684°。
这一现象支持夹持残余偏斜的解释，但不证明其他失败都有相同原因。

当前实验配置为 `modules/cube/configs/mechanical-rx-optimized.json`。
它沿用16分段合并几何、0.5毫秒步长和原最终验收线，每个对齐检查最多恢复一次。
恢复仅在等待超时且另一爪接触可靠、偏差位于原恢复范围内时执行，不在每步增加固定开合。
恢复动作独立记录在报告的 `alignment_regrasps` 中，不包含在搜索的静态预计成本中。

| 同一打乱及还原 | 仿真时长 | 计算耗时 | 结果 |
| --- | ---: | ---: | --- |
| 历史基础路径，合并几何 | 26.20秒 | 428.62秒 | 通过 |
| 搜索路径，关闭恢复 | 23.05秒 | 338.18秒 | 最终对齐失败 |
| 搜索路径，最多一次恢复 | 24.50秒 | 362.93秒 | 通过 |

通过案例的最终位置误差0.280毫米，姿态误差0.684°；仅最终阶段增加A爪开、合两个动作。
相对基础路径，仿真时长减少6.5%，本次计算耗时减少15.3%；并行负载不同，后者不作为稳定加速比。
六步 `R U F2 L' D B` 验证在首个R转动时发生 `piece_18` 脱块，退出码1。
仿真5.95秒、计算90.95秒，未完成任何输入动作检查点，没有求解结果。
该失败使用原三层卡脚，说明短流程成功不能推广为长序列稳定。

## 复现

在仓库根目录操作。先按[RX准备与运行](mechanical-rx.md#准备与运行)安装依赖并校验资产。
短流程命令：

```bash
./rm cube --mechanical \
  --rx-bundle assets/rx_gripper/mujoco_linkage_v5 \
  --mechanical-config modules/cube/configs/mechanical-rx-optimized.json \
  --scramble "U F2" --solve \
  --output output/cube-mechanical/optimized-uf2-check
```

如目录已存在，换一个新的输出目录。退出码0及报告中的 `passed:true`、`solved:true` 同时成立才算通过。
失败时保存报告，检查最早失败动作，不用静态扫描通过替代动力学验收。
同状态单步性能对照使用[独立复现工具](mechanical-rx.md#单步故障复现)，查看 `dynamics_wall_time_s` 与 `timers`。
更换几何后仍须匹配相同关节与状态布局；快照恢复只用于独立诊断，不能拼接成连续还原录像。

## 当前结论与验收

采用16分段共面合并、0.5毫秒步长作为长序列候选，原默认几何不变。
历史几何改动的全套测试通过20项C++、19项Rust、34项Node测试；64份文档检查通过。
七组非法网格参数边界均被拒绝，独立代码复核未发现合并填平内腔的问题。
未接入动作优化的完整二十步对照已按用户要求停止，不会自动恢复。
后续使用动作优化与有限恢复配置逐级验证；不能把上述短序列成功称为长序列通过。
