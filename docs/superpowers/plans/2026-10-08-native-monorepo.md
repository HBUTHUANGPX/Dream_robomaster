# 原生统一仓库迁移计划

本文是 2026-10-08 已完成的历史迁移计划。
当前启动方法见[仓库首页](../../../README.md)。
设计依据见[原生统一仓库设计](../specs/2026-10-08-native-monorepo-design.md)。

## 目标与结构

目标是让三个仿真模块在同一仓库中使用 C++/Rust 运行。
C++ 进程执行仿真。Rust 提供网页服务。
模块共享资产与网页，不在原生运行中调用 Python。

使用的组件包括 C++20、MuJoCo、Eigen、OpenCV、nlohmann JSON、Rust、Cargo 和 CMake。

## 共用约束

- 保留资产、许可证和原始数据。
- 模块工作者只修改分配的模块与模块说明。
- 主工作者负责根目录、公共库、Rust、目录迁移和集成。
- 完成前执行实际行为测试。
- 未达到行为一致的功能必须报告。

## 审查重点

- 非法 JSON 和非有限数值不能导致进程意外终止。
- 本地端口转发后，网页控件仍可正常调用接口。
- 物理仿真保留接触驱动，不以状态动画代替。
- 魔方求解器必须处理无转动历史的状态。
- 图像检测、传感器估计与渲染必须在原生程序中执行。
