# RX 窄指尖接触几何实施计划

用户已授权改进窄指尖。保留 RX 连杆、原碰撞体、力矩上限、摩擦夹持和不进退约束。
本次交付为可复现的窄指尖设计与单层验证工具，不把简化单层探针等同于完整魔方还原。

## 设计与步骤

- [x] 对比十二、十四和十六毫米见方的指面，选择十六毫米指面与十八毫米长的连接颈，保持原内侧接触平面，增加质量和惯量。
- [x] 固定安装外移四十一点八九一毫米，避免原宽指参与夹持和相邻层扫掠。
- [x] 对齐原指面的接触参数，检查新增件的同手自碰撞、双爪碰撞和错误层接触。
- [x] 检查两手正反向九十度和半圈，记录每个指面的承载、物体位姿和电机力矩。
- [x] 封装 C++ 诊断程序，保存来源校验、参数、视频和复现说明。
- [x] 完成针对性验证与仓库测试，提交并推送。

## 验证标准

每个单层动力学试验必须完成十二秒：先预置并夹持，再加载重力，转动并保持。
终态层角误差不超过零点五度，基体最大偏转不超过一度，最大平移不超过一毫米。
不得出现掉落、数值警告、双爪碰撞、新增件与同手机构的干涉或满足检测阈值的错误层接触。
几何扫描还要覆盖正反方向、空腕回位、整体换向和完整开合行程。
记录接触检测阈值和简化模型局限，避免用视频观感替代验收。

## 本次结果

默认十六毫米指面及 −1.20 rad 夹持目标下，八个有符号单层转动案例均通过。
最大终点角误差 0.378311°，基体最大平移 0.414954 mm，最大偏转 0.383608°。
原宽指未承载，四个新增指面均持续承载。三千一百零二个几何采样姿态未检出禁碰。
完整仓库测试通过，独立审查指出的输出链接覆盖问题已复现并修复。
