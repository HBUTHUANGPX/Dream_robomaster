# RX 完整还原提速验证

本文记录2026-10-09的提速工作。当前入口见[RX指南](../../rx-narrow-tip.md)。

## 验证方案

1. 固定上一轮20步打乱和62元动作计划，分别提高腕速与开合速度。
2. 保留摩擦、执行器上限、接触模型和全部物理检查。
3. 对通过的推荐参数复验34个动作场景，并重新求解、录制实时视频。
4. 在测试入口增加独立速度参数，使验证可复现；更新运行指南。

速度倍率仅缩短已有控制斜坡。固定稳定等待暂时保留，不把播放加速算作执行提速。

## 实测结果

同一62动作计划在16倍腕速、32倍开合下用时44.555秒，基线为196.18秒。
32倍腕速也通过该计划，用时41.189秒，但腕部峰值力矩达到15 N·m上限；16倍在该序列中约8.636 N·m，因此推荐16/32。
16/32和32/32各通过34个独立物理案例。
16/32通过两组重新求解的20步打乱还原，分别为62动作44.555秒、70动作50.345秒。
两个案例的内部面电机力、禁触和数值警告均为零。
正距离接触力回归、默认参数兼容案例和七项非法参数检查均通过。
本次 `./rm test` 全部通过：20项C++测试、19项Rust测试、34项Node测试和54份文档检查。
原始报告和实时录像保存在 `output/rx-speed/`。
只增加测试程序的速度参数和使用说明，运行时模型、执行器控制实现和默认倍率均未修改。
