# RX 窄指尖接入完整还原

本文是 2026-10-09 的实施记录。当前操作入口见 [RX 接入指南](../../rx-narrow-tip.md)。

## 目标

把用户提供的 RX 闭环夹爪接入当前 C++ 完整魔方和十二元动作执行器。
使用 55 mm 魔方、固定安装和摩擦夹持。
默认 Robotiq 入口保持兼容。

## 实施步骤

1. 导入原始夹爪几何、惯性和闭环约束，加入已验证的窄指尖。
2. 两只夹爪均将竖向夹持设为腕关节零位，检查与软件机械状态的对应关系。
3. 参数化魔方尺寸，适配电机目标和开合反馈。初版使用保守速度。
4. 接入 `--rx-bundle`、报告、求解耗时估计和录制。
5. 从完整模型单步、换手、整块旋转逐步验证到完整还原。
6. 运行回归测试，更新中文入口和故障说明，推送已验证改动。

## 验收

求解序列先通过软件回放，再执行物理仿真。
物理报告必须确认贴纸状态还原、块体对齐、无数值警告、无禁止接触。
执行阶段关闭魔方层电机，不添加夹持焊接或强制位置跟随。
保留失败报告；失败时不把规划成功等同于物理还原成功。
原始大体积资产保留在用户本地，不加入 Git。

## 安装映射审查

两手固定安装均绕各自腕轴增加九十度。
逻辑零位的两对接触面分别位于 X 正面和 Y 负面，夹持方向都沿 Z。
十六毫米接触面在 X、Y 投影各有约 2.33 mm 间隔。
逻辑偶数腕角对应原单层探针的竖向支撑姿态。
元动作方向和面转符号不变，保留原软件机械状态图。
验收额外覆盖支撑腕正负一百八十度，不能仅凭几何对称假设其可用。

## 实施结果

固定安装映射和十二元动作执行完成。
完整模型的单手支撑暴露了接触约束过软问题，保留失败记录后调整了魔方侧接触及摩擦约束的数值刚度。
最终参数、原资产边界和可复制命令统一写入当前指南。
没有提高误差阈值、摩擦系数或夹爪力矩上限。
实际预紧力随接触参数变化，不把这次结果表述为实机验证。

二十步打乱经六十二个元动作完成物理还原，执行约 196.18 秒。
十八次锁层前检查均在理想约束重绑定之前通过。
带最终检查的三十四个物理动作案例全部通过。
补充正距离接触力判据后，同一六十二动作序列和三十四个物理案例再次通过。
正距离错误层受力回归在隔离编译的旧判据下失败，在当前判据下通过。
最终 `./rm test` 通过二十项 C++、十九项 Rust、三十四项网页与入口测试及五十三份文档检查。
生成报告、失败对照和实时视频保存在 `output/rx-full-solve/`，不随源码提交。
