# 连续接触魔方与RX夹爪融合

## 目标

复用RX窄指尖、90度安装和现有动作规划。手腕与夹爪由执行器驱动，指尖靠摩擦传力。魔方中心与自由核心连接，棱角块继续靠卡脚保持；不重绑定内部约束、不在运行中重设位姿。

## 实施与验收

1. 为机械入口增加RX场景组合，移除六个中心驱动，加入自由核心及一次性上料固定装置。
2. 初始化时设定RX闭环装配坐标；外部动作只控制执行器。夹持确认后解除上料装置。
3. 测量双指接触、腕跟踪、核心漂移、脱块与物理色块状态。
4. 先验收夹持和单层往返，再执行换手、整块旋转和跨轴动作。
5. 通过后接入物理状态求解，录制视频，运行回归测试并更新入口文档。

## 边界

RX连杆的固定connect约束与一次性外部上料约束需独立统计；它们不用于保持魔方棱角块或转层。
未通过的阶段必须报告失败，不能通过逻辑状态或位姿吸附补齐。

## 机构调整记录

移除中心电机后，单纯的轴摩擦不能可靠对齐自由层。加入恒定的四周期势能，模拟磁力魔方的被动定位。
每轴力矩为 `-A*sin(4*q)-0.0005*v`，仅使用实际轴角和速度，不读取动作序列或目标角。
其势能为 `A*(1-cos(4*q))/4`，外部夹爪必须做功克服定位势垒。
定位近似与实体卡脚保持是两个机制，文档和报告分别标明。

## 验收进度

五个步骤均已完成。R面与U面分别完成物理打乱、求解及还原；U面案例覆盖单手整块转向与换手。
R面零摩擦对照出现核心滑移，未通过验收。当前版本另验证转腕期间的实际切向接触力与最终承重。
命令、结果和未覆盖边界见[连续接触模型的RX接入说明](../../mechanical-rx.md)。
