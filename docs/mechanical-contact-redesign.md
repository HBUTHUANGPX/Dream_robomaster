# 魔方接触结构再设计实验

## 当前方案：关节导向与外壳接触

内部保持不再全部依赖软碰撞。新增 `retention_mode=1`：20个棱角块通过同心球关节连接核心，六个中心块仅保留转轴。
球关节限制径向平移，允许块绕不同轴连续转动。26个外壳负责接触传力和相邻层阻挡。
卡脚、底托、颈部和中心预紧滑动关节不参与此模式；球芯仅显示。
RX夹爪仍靠执行器与摩擦驱动，连接关系运行前固定，不按转层切换，不重设块位姿。
该模式不模拟飞棱；错位强转导致的卡死和接触载荷应单独评价。

结构参考下表所列的MuJoCo官方三阶模型，没有引入其较大的关节惯量参数。
球关节阻尼为0.00002，armature为0.00000001。运行入口见[RX机械魔方](mechanical-rx.md)。
以下卡脚改造、软限位和预紧实验均为历史记录，适用于 `retention_mode=0`。


## 目标与约束

本轮优化卡脚的接触表达，不改动作搜索、时间步长、驱动力或最终验收线。
棱块、角块仍使用自由刚体，由实体接触保持。没有新增保持约束或运行位姿修正。
减小碰撞体数量不等于稳定；静态扫描、单步诊断和完整流程分别记录。

原选择性分层六步流程完成打乱，在还原第4步F2脱块，只完成9个输入检查点。
原报告用时48.20仿真秒、662.10计算秒，`passed:false`，没有完整还原结果。

## 圆滑承托环

`cap_collision_mode:1` 用胶囊体组成周边承托环和四条分段辐条，替代卡脚的密集凸楔体。
中心环保留轴向缺口形状，辐条连接颈部和环。球芯、棱块底托、外壳和惯性不变。
模型变更会减少接触面积，不能假定与原实心球壳卡脚完全等价。
生成时校验胶囊弦段到球芯的净空，拒绝默认尺寸下侵入核心的8分段配置。

实验参数为 `modules/cube/configs/mechanical-rx-rim-experimental.json`。
场景几何体由选择性分层的1749个降为1253个，圆周仍为16分段。
静置夹持通过，`R U` 构型的六面438角度扫描没有检测到内部穿透。

同一普通R快照的1.65秒动作诊断：

| 指标 | 选择性分层 | 承托环 |
| --- | ---: | ---: |
| 碰撞计算 | 8.49秒 | 4.83秒 |
| 整段计算 | 22.19秒 | 15.24秒 |
| 单步位姿 | 通过 | 通过 |

本次总计算减少约31%，碰撞计算减少约43%。这些计时受并行机器负载影响，不保证固定加速比。
两个已知脱块快照中，承托环均未触发脱出；R末态位置误差0.498毫米，通过单步判据。
F2末态位置误差0.644毫米、姿态误差0.02090弧度，未通过单步严格判据，不能记作成功。
原几何对应诊断在1.10秒和1.25秒时检测到 `piece_18` 脱块并提前结束。

从初态执行 `U F2` 打乱及还原通过：退出码0，`passed:true`、`solved:true`。
仿真24.45秒、计算231.47秒，恢复一次；最终位置误差0.403毫米、姿态误差0.539°。
选择性分层同短流程计算326.02秒，本次减少约29%；这包含恢复和输出，不是单独碰撞计时。
承托环六步连续流程仍在还原第4步F2发生 `piece_18` 脱块，完成9/12个检查点。
仿真48.85秒、计算481.83秒，未触发恢复，没有完整还原结果。
相对原选择性分层的662.10秒，失败前计算减少约27%，但两组都失败，不能将其当作完成还原的加速比。
下一项诊断记录中心轴向位移，检验原1.5毫米向外行程是否削弱了卡脚保持。

## 中心软限位诊断

承托环自身F2失效前，六个中心轴向位置约为负0.4毫米。
转动过程中最大向外位移达到3.169毫米，超过模型1.5毫米名义上限；软限位允许受力超程。
同一快照仅改变中心滑动关节参数，得到以下结果：

| 改动 | 最大向外位移 | 结果 |
| --- | ---: | --- |
| 原参数 | 3.169毫米 | 脱块 |
| 上限改为0.35毫米 | 3.938毫米 | 脱块 |
| `solreflimit` 改为 `0.002 1` | 2.456毫米 | `piece_9` 脱块，同时出现较大整体偏移 |
| 同时修改上限与 `solreflimit` | 1.193毫米 | 提前失败，整体支撑偏移超限 |

这些失败的推进时长不同，不比较耗时。没有把任一限位改动加入运行配置。
中心张开过大是观测事实，但收紧限位不足以解决；下一步须检查偏心夹持和内部接触载荷的关系。
复现使用[承托环F2快照](../assets/mechanical_cube/README.md)，只在独立诊断场景中修改六个 `preload_*` 关节。
改上限时保留下限负1.5毫米，其余参数、状态、控制目标不变。不在运行中修改模型或状态。

诊断报告新增 `initial_center_preload_m`、`max_center_outward_m`、`final_center_preload_m` 及采样轴向位移。
转层中的部件位姿误差是相对最终目标计算，不等同于径向脱出；脱出另由径向检查判定。

## 偏心与圆滑底托对照

承托环F2快照中，核心相对腕轴交点偏移约1.20毫米。
独立诊断仅在初始化时平移整个魔方，保持内部相对位姿不变。
居中后不再脱块，中心最大向外位移为0，峰值接触力5.66牛；末态位置误差0.674毫米，仍失败。
这说明整体偏心是重要诱因；不证明内部结构已可靠。正式执行没有加入平移或位姿修正。

`bearing_collision_mode:1` 将棱块96个底托凸片改为圆截面胶囊体，保留相同显式质量和惯性。
几何体数量不变。横截面收窄，但半球端帽越过原端面，沿弧方向覆盖约正负22.16度。
实验配置为 `modules/cube/configs/mechanical-rx-rounded-bearing-experimental.json`。
普通R单步位姿通过，`R U` 构型六面438角度扫描通过。
原偏心F2快照没有脱块，但末态位置误差2.044毫米、角度误差0.07980弧度，仍失败。
不能据此把圆滑底托宣布为稳定性修复。

两组仅增大外壳倒角的诊断均脱块，倒角分别为1.5和2毫米，暂不采用。
圆滑底托下将夹持力矩降到0.15或0.20牛米，均触发整体偏移超限。
将定位力矩降到0.04牛米也失败。这些对照未写入推荐配置。

圆滑底托六步连续流程仍在还原F2时脱块，计算474.92秒，完成9/12个输入检查点。
本次为 `piece_5` 脱出。该方案不能单独解决连续稳定性。

## 双向倒扣与接触求解对照

`bearing_collision_mode:2` 是防飞棱结构原型。球芯半径由10.7毫米减为9毫米。
棱足在9.8毫米半径处设置两排圆弧凸缘，横向中心分别位于正负8度，管半径0.65毫米。
两端相连，中部增加0.35毫米半径横梁与延长的颈部连接。
每个棱足使用19个胶囊体；不是原球壳的等价简化。
生成器检查胶囊弦段的球芯净空。参数见 `mechanical-rx-torpedo-experimental.json`。

原型的 `R U` 构型六面438角度扫描无干涉，普通R单步通过。
已知偏心F2中没有径向飞出，但末态严重失位，仍失败；该项初筛使用尚未添加中部横梁的场景。
不能用没有飞出代替成功完成转动。

新增 `rm_cube_mechanical_retention` 诊断程序固定邻块，逐块沿径向外移。
F面扫描0至90度、间隔15度，每个角度检查20个自由棱角块，共140个样本。
位移采样间隔0.1毫米，接触穿透超过20微米视为遇到阻挡。
中心统一向外张开1毫米时，原承托环最迟在1.3毫米外移后受阻，新倒扣为0.5毫米。
两组均无零位干涉，均在3毫米范围内发现阻挡。它只验证固定邻块的离散几何，不验证协同脱出或动力学。

按[诊断准备说明](mechanical-rx.md#单步故障复现)安装依赖后，在仓库根目录执行：

```bash
mkdir -p .cache/tmp
TMPDIR="$PWD/.cache/tmp" cmake --build build --target rm_cube_mechanical_retention -j4
build/bin/rm_cube_mechanical_retention \
  output/cube-mechanical/retention-scene/scene.xml \
  output/cube-mechanical/retention-open1mm.json 0.001
```

先按[资产说明](../assets/mechanical_cube/README.md)生成输入场景，替换为要比较的模型配置。
省略最后参数时中心张开量为0。输出目录必须存在，已有报告请换新路径。
退出码0表示扫描完成，不表示动力学成功；同时检查零位干涉与无阻挡样本数。

内部接触维数 `internal_contact_dimension` 默认3；实验值1仅保留法向接触，忽略内部摩擦。
夹爪与外壳的显式摩擦接触仍为4维。此近似参考MuJoCo官方魔方，不能称为原物理模型的等价加速。
同一普通R中，圆滑底托法向接触计算5.90秒，原3维接触计算15.23秒，两者位姿均通过。
原偏心F2在两种内部接触下仍失败，因此不能只靠省略摩擦修复脱块。

## 指垫顺应性对照

新增 `rx_tip_contact_time_s`，默认0.004秒。它仅修改指尖与外壳显式接触对的时间常数。
更大的值用于模拟较软指垫；没有更改夹持摩擦、执行器力矩、腕轴、元动作或内部约束。
该参数尚未通过真实指垫材料辨识，不把数值柔度当作已测得的硬件属性。

圆滑底托的同一偏心F2快照，将时间常数改为0.016秒后，没有脱出。
最大中心张开0.270毫米，末态块间位置误差0.462毫米，角度误差0.01210弧度。
核心仍偏移约1.044毫米，超过1毫米限值，因此单步严格判据仍失败。
普通R通过；后续从初态比较保留内部摩擦和仅法向接触的完整六步流程。

仅法向接触、0.016秒指垫时间常数的六步流程计算177.07秒，在还原F2开始前对齐超时。
当时块间位置误差0.402毫米，但核心偏移约2.18毫米，超过中间检查的2毫米限值。
未放宽阈值继续强转。这说明过软指垫也会增加整颗魔方漂移，不能只根据单步内部误差选参数。

保留内部摩擦的0.016秒配置也未通过六步：计算493.32秒，在还原F2时脱块。
法向接触、0.008秒配置计算170.37秒，仍在F2脱块；转动前核心偏移约1.79毫米。
将中心预紧刚度从500增至2000牛每米仍失败，不将其作为稳定性修复。

## 单手悬持的缓慢滑移

新快照显示：一只夹爪打开后，核心先向下偏移；后续整块翻转把下垂转成横向偏心。
腕角跟踪误差约为万分之一弧度，不能归因于同等量级的腕控制角误差。
原接触共有8个指垫接触点，总法向力约13.25牛。不能把它误判为单点接触或仅靠增加摩擦系数处理。

MuJoCo的软接触摩擦不保证静止粘着；持续切向载荷可能产生缓慢滑移。
官方建议使用椭圆摩擦锥，并增加摩擦方向相对法向的阻抗，见[接触建模说明](https://mujoco.readthedocs.io/en/stable/modeling.html?highlight=urdf)。
本模型已经使用椭圆锥，新增 `friction_impedance_ratio` 参数，默认保留10。
它不增加摩擦系数、不添加粘附力、不改变关节或位姿，也不保证绝对无滑移。

同一B整块翻转快照中，仅将阻抗比改为100：核心偏移从约0.872毫米降到0.440毫米。
核心姿态误差从0.02985弧度降到0.01309弧度，块间位置误差约0.402毫米，单步严格判据通过。
将扭转摩擦长度从2毫米改为6毫米只改善到约0.822毫米、0.02713弧度，仍失败，未采用。
完整流程使用 `mechanical-rx-low-slip-experimental.json` 继续验证，不能以单步通过代替连续验收。

## 连续曲面原型

`cap_collision_mode:2` 使用模块内的 `rm.cube.cap` 距离场插件。
球壳、角度边界和中心轴向缺口的边界函数取最大值，保持内腔和对角翼。
场值在交界外侧不是精确欧氏距离，不可微位置使用有限的单侧梯度。
插件只计算几何距离及梯度，没有积分状态、附加驱动力或姿态修正。

单元测试覆盖边界符号、缺口、有限差分梯度、包围盒、插件注册及数据复制和释放。
实际接触算法仍可能更慢或漏检，不能仅以字段测试通过认定动力学有效。
MuJoCo对非凸距离场使用多起点搜索，见[官方插件说明](https://mujoco.readthedocs.io/en/stable/programming/extension.html)。
实验参数为 `modules/cube/configs/mechanical-rx-sdf-experimental.json`，不作为当前推荐配置。
该插件编入本仓库程序；距离场场景需由本仓库入口或诊断程序加载，外部MuJoCo查看器不会自动注册它。

该原型静置夹持通过，场景655个几何体；1.90仿真秒计算194.83秒，明显慢于承托环的20.83秒。
`R U` 构型六面扫描438个采样通过。
在独立诊断场景中将 `sdf_initpoints` 减至8后，普通R位姿通过，但计算仍需48.17秒。
这些结果表明，非凸接触搜索的开销抵消了减少碰撞体的收益；不能将几何体最少等同于最快。
低采样仅用于初筛，尚不写入运行配置或作为可靠碰撞检测方式推广。

将起点进一步减至1时，普通R和已知F2动态诊断均被MuJoCo的接触数量检查中止：
碰撞函数返回2个接触，而 `pairMaxContact` 仅预留1个。
同场景静态六面扫描仍通过，说明静态通过不能替代动态验证。
本轮不采用距离场作为提速方案，保留实现与实验配置供复现，不再启动其长流程。

专项源码复核确认，插件生成网格不需要手动减去包围盒中心。
MuJoCo的距离场有限起点与线搜索不保证找到所有薄接触；不能用降低采样无条件换取速度。

## 复现与失败处理

在仓库根目录，先按[RX准备说明](mechanical-rx.md#准备与运行)安装依赖并校验资产。
承托环短流程：

```bash
./rm cube --mechanical \
  --rx-bundle assets/rx_gripper/mujoco_linkage_v5 \
  --mechanical-config modules/cube/configs/mechanical-rx-rim-experimental.json \
  --scramble "U F2" --solve \
  --output output/cube-mechanical/rim-uf2-check
```

退出码0且 `passed:true`、`solved:true` 同时成立才通过。输出目录已存在时使用新目录。
失败时保存报告，不放宽最终阈值，不自动重复长序列。
距离场实验仅将参数路径替换为上述距离场配置，输出改为新目录。

同快照比较使用[独立诊断程序](mechanical-rx.md#单步故障复现)和[已保存诊断资产](../assets/mechanical_cube/README.md)。
报告记录实际步数、平均和最大接触数、有效碰撞体数与场景来源。
`active_geoms` 指掩码非零或被显式碰撞对引用的几何体，不代表每步实际发生接触的几何体。
只有相同快照、相同动作时长且均通过的完整步数运行可比较速度，失败早停的计时不得混入。
