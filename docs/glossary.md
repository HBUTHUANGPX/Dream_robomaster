# 技术术语表

本表解释文档中的程序名称和技术缩写。
这些名称是程序标识，命令中保留原文。
首次启动只需按[首次使用指南](getting-started.md)操作，无需先掌握全部算法。

## 环境与运行

| 名称 | 中文含义或用途 |
| --- | --- |
| C++、Rust | 当前仓库使用的两种编程语言 |
| Bash | 执行根入口和准备脚本的命令解释器 |
| CMake、Ninja | 配置和编译 C++ 程序的工具 |
| Cargo、rustc | Rust 的依赖与构建工具、编译器 |
| SDK | 软件开发包，包含编译需要的头文件和库 |
| MuJoCo | 计算机器人运动与物体接触的物理引擎 |
| OpenGL、EGL | 图形绘制接口，以及创建渲染环境的接口 |
| GLFW | 创建桌面窗口并读取键盘、鼠标的库 |
| DISPLAY | 标识 Linux 图形会话的环境变量；有值不代表驱动一定可用 |
| FFmpeg | 将图像帧编码为视频的工具 |
| Node.js | 运行网页脚本和入口测试的工具；网页服务本身不使用它 |
| HTTP | 浏览器与服务传递请求、状态和图像所用的协议 |
| JSON、JSONL | 结构化文本格式，以及每行一条 JSON 的记录格式 |
| RPC | 进程间命令调用；本仓库通过逐行 JSON 调用 C++ 仿真 |
| SSH | 登录远程主机及转发端口的工具与协议 |
| SHA-256 | 文件摘要算法；用于检查文件内容是否改变 |
| x86_64、amd64 | 本仓库支持的 64 位处理器架构的两种名称 |

## 导航与自瞄

| 名称 | 中文含义或用途 |
| --- | --- |
| IMU | 惯性测量单元；本仓库模拟角速度和比力测量 |
| ICP | 迭代最近点算法；将点云配准以估计运动 |
| SLAM | 同时定位与建图；代码中的 `slam` 表示在线建图模式 |
| A* | 在地图中搜索路径的算法 |
| DWA | 动态窗口法；在可实现的速度范围内选择局部运动 |
| PID | 比例、积分、微分控制；用于跟踪目标运动 |
| RGB | 红、绿、蓝三个图像颜色通道 |
| OpenCV | 图像处理与视觉计算库 |
| ONNX | 保存和交换神经网络模型的格式 |
| PnP | 根据三维点及其图像位置求解相机与目标相对姿态的方法 |
| EKF | 扩展卡尔曼滤波；用于融合测量并估计目标状态 |
| ROS、catkin | 机器人通信与工具环境，以及 ROS1 的构建工具 |
| ROS bag | 按时间保存 ROS 消息的数据包 |
| FAST-LIO | 使用雷达和惯性测量估计运动的上游算法项目 |
| 2.5D 地图 | 每个水平位置记录一个上表面高度的地图 |
| 外参 | 两个传感器坐标系之间的位置与旋转关系 |

## 模型与魔方

| 名称 | 中文含义或用途 |
| --- | --- |
| CAD、STEP | 计算机辅助设计，以及保存设计几何的交换格式 |
| OCCT | OpenCASCADE 的几何建模与网格化开发库 |
| STL、OBJ | 保存三角网格及模型几何的文件格式 |
| XML、MJCF | 结构化标记格式，以及 MuJoCo 使用的模型描述格式 |
| Kociemba | 当前原生魔方模块使用的通用求解器 |
| R、L、U、D、F、B | 魔方右、左、上、下、前、后六面的转动标记 |
| `'`、`2` | 魔方转动中的逆时针和半周后缀；完整约定见模块说明 |
| 无窗口 | 不创建桌面窗口；生成图像时仍需要渲染驱动 |
| 双夹爪 | 两个通过接触和摩擦操纵魔方的夹爪 |
