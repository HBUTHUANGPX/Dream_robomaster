## 历史记录：为什么延长并收窄

上一轮原厂手指约 37.3 mm 宽的内侧面，在固定中心转层路径中碰到相邻层。
只用原指尖前端浅夹，虽然可以持物，单层动力学试验仍出现偏转或掉落。
新增延长件让原宽指远离魔方，用独立的窄指面接触目标块。

历史原型对比了十二、十四和十六毫米见方的接触面。
在同一单层半圈原型、相同夹持目标 −1.25 rad 下，终态角误差分别约 0.70°、0.54°、0.43°。
因此选择十六毫米指面。连接颈为十八毫米长、八毫米宽，内侧面位置不变。
这些是选择尺寸时的原型结果；当时封装的单层程序验收记录见下节。

## 完整还原入口

先完成前述准备。以下命令在仓库根目录执行。
`--rx-bundle` 的值是原包目录，不是生成的 `scene.xml`，也不是压缩包文件。
以下命令采用已完成完整还原录像的20步序列、3000毫秒预算和三个搜索线程：

```bash
./rm cube --dual \
  --rx-bundle .deps/rx-gripper/RX_ASSY_V2_with_gripper/mujoco_linkage_v5 \
  --headless --scramble "R U F' L2 D B R' U2 F D' L B2 U' R2 F2 D L' U B' R" --solve \
  --search-ms 3000 --search-threads 3 \
  --speed 1 --wrist-speed 1 --jaw-speed 1 \
  --record --playback 1 --output output/rx-full-solve/demo
```

`--headless` 不需要桌面，但录像仍需要EGL和FFmpeg。
不录像时去掉 `--record`。只规划时将 `--solve` 换为 `--plan-only`，并去掉录像参数。
`--plan-only` 仍创建模型并打乱；找到软件计划不表示执行通过。
命令执行结束后返回终端。中途停止使用 `Ctrl+C`，未结束的视频和报告可能不完整。
再次运行前换一个输出目录，不用旧文件判定本次结果。

首次完整还原验收使用以下保守时长和速度倍率1。它们是仿真控制设置，不是实测硬件性能。

| 操作 | 速度倍率1时的斜坡 | 额外稳定等待 |
| --- | ---: | ---: |
| 腕部90°或180°旋转 | 3秒 | 0.5秒 |
| 夹爪打开或闭合 | 2秒 | 0.5秒 |

`--wrist-speed` 和 `--jaw-speed` 分别缩放斜坡，稳定等待不缩放。
`--speed` 为未单独指定的速度提供倍率。`--playback 1` 只表示实时播放。
预计成本还计入闭合抓取约0.08秒，以及单层旋转的面锁定与抓取约0.15＋0.08秒。
接触等待和物理步长取整会影响实际耗时，不能把预计成本当作实测时间。
RX速度以本模型的实测结果为准，推荐提速参数见下节。

进入相应阶段后，输出目录保存场景、计划、动作明细和控制配置；录像保存为 `demo.mp4`。
`controller_profile.json` 中检查 `gripper:rx_narrow_tip`、显式 `rx_bundle` 和 `cube_side_m:0.055`。
`robot_plan.json` 的 `found:true` 只表示软件找到计划。
完整物理结果须核对本次进程退出码、`verification.json` 的 `solved`、运动与接触记录及数值警告；启动或执行失败时不保证这些文件全部生成。
执行失败时保存 `failure.json` 和终端错误，按[位姿滑移排查](troubleshooting.md#rx-接入与位姿滑移)处理，不关闭检查后继续。
源辅助几何组3和标记组4在视频与RPC图像中隐藏，这不改变碰撞参与情况。

RPC启动也支持相同 `--dual --rx-bundle PATH` 参数。`reset` 保留该路径，重建RX场景。
RPC标准输出仅为逐行JSON，诊断写标准错误；接口格式见[魔方模块](modules/cube.md#原生进程接口)。

### 完整流程禁碰判据

RX使用接触margin，`dist > 0` 时仍可能传递法向力，因此不能只检查几何穿透。
完整流程采用以下判据；“或”表示任一条件命中即拒绝继续执行。

| 检查类别 | 命中条件 |
| --- | --- |
| 新增延长件与同手可动机构的禁触 | `dist < -0.00001 m` 或法向力 `> 0.01 N` |
| 旋转时其他被判为禁触的接触 | `dist < 0` 或法向力 `> 0.01 N` |
| 错误层受力接触 | 法向力 `> 0.01 N`，不要求 `dist < 0` |

该补充修复监测漏项，不调整接触物理参数或控制时长。
新增判据下，同一62动作完整还原和34个物理案例均通过。专门的 `--check-margin` 回归使用真实夹持接触，确认几何未穿透但错误层受力时仍会拒绝。

## 生成场景与扫描几何

生成 A 主动转动的场景：

```bash
build/bin/rm_cube_rx_tip_geometry \
  .deps/rx-gripper/RX_ASSY_V2_with_gripper/mujoco_linkage_v5 \
  output/rx-tip-validation A
```

生成 B 主动转动的场景：

```bash
build/bin/rm_cube_rx_tip_geometry \
  .deps/rx-gripper/RX_ASSY_V2_with_gripper/mujoco_linkage_v5 \
  output/rx-tip-validation B
```

程序分别生成 `dual55.xml`、`dual55B.xml` 和对应扫描 JSON。
最后可以追加接触面的边长参数，例如 `14`；默认值为 `16`，单位毫米。
非默认尺寸属于新的试验，不能沿用默认尺寸的验收结论。

扫描覆盖正反方向的回位、单层转动、整体换向，以及完整开合行程。
转动以一度为间隔，开合以百分之一闭合量为间隔；它是有限采样，不是连续碰撞安全证明。
检查报告中的 `first_forbidden_deg`、自碰撞、跨层接触和支撑接触情况；没有接触到魔方的姿态不能算可夹持方案。
场景文件保持源模型的 CAD 参考关节零位，动态程序负责设置满足闭环的实际起始姿态；不要直接把 XML 默认零位当作就绪姿态。

## 执行单层动力学验证

执行 A 正向九十度，并生成视频和逐步数据：

```bash
build/bin/rm_cube_rx_tip_probe output/rx-tip-validation A 90 A90
```

参数依次为结果目录、主动手、目标角度和可选输出标记。
主动手可选 `A`、`B`；角度可选 `90`、`-90`、`180`、`-180`。
更换手和角度，同时更换输出标记，可完成两手共八种转动试验。
同一标记的报告和视频会被覆盖。

每次试验先预置魔方并用执行器闭合，第四秒加载重力，第六至第九秒转动，随后保持至第十二秒。
前四秒没有重力，不代表从任意初始状态抓取。两指的电机目标为 −1.20 rad，力矩上限仍为源模型的 ±0.6 Nm。
没有抓取焊接、位置跟随约束或执行中的进退动作。运行期间不改写魔方或层的关节位置。

A 主动时，初态为 A 腕零度、B 腕九十度，转动 x 正侧外层。
B 主动时，初态为 A 腕九十度、B 腕零度，转动 y 负侧外层。
报告区分主动手与支撑手；力数组保持物理 A、B 顺序。

## 验收范围与失败处理

单层探针由一个自由基体、一个独立转动的外层和其余合并刚体组成，总魔方质量为 156 g。
名义边长为 55 mm，实体碰撞外包尺寸约 54.358 mm，沿用既有魔方的缝隙比例。
没有完整魔方内部机构、定位与实测转层阻力，块间碰撞关闭。
单层试验本身不能证明完整还原，也不能单凭它复用Robotiq的机械状态图或高速参数。
本次完整场景的安装零位、独立物理案例与完整还原证据见[接触参数与验证边界](#接触参数与验证边界)。

每个动力学案例同时检查：

- 完成十二秒，终态外层相对基体的角度误差不超过 0.5°。
- 基体最大偏转不超过 1°，相对预置位置的最大平移不超过 1 mm。
- 无数值警告、双爪碰撞、新增件与同手可动机构的干涉或检出的错误层接触。

几何穿透阈值为一微米；动力学同手及双爪干涉阈值为十微米。
动态错误层接触要求穿透超过一微米、法向力超过 0.01 N，覆盖全过程。
接触零计数仅表示未检出超过这些阈值的接触。
另外报告各指面承载、原宽指承载和电机实际峰值力矩，避免把原指面偷偷参与支撑当成窄指尖的成绩。

程序保存 JSON 和 MP4。动力学报告 `final_passed:true` 且退出码为零才表示该单层案例通过。
若为 `false` 或程序非零退出，保留输出，先区分机械验收失败、资产加载失败与录像失败；不要只看视频判断。
源网格缺失时检查解压结构。扩大指面后出现跨层接触时，恢复已验证尺寸再排查安装位置。
