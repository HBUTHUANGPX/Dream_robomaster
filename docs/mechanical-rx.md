# 机械魔方的RX摩擦夹持

## 机构与执行边界

该入口把[机械魔方模型](mechanical-cube.md)接到两只成90度布置的RX窄指尖夹爪。
核心为自由刚体。只有两个腕轴和两个夹爪电机用于外部操作，六个中心轴没有驱动电机。
默认 `retention_mode:0` 的棱角块由实体卡脚接触保持。
实验 `retention_mode:1` 使用20个球关节和6个中心转轴，均同心于自由核心。
模式1无轴向预紧滑动关节，不生成卡脚、颈部或底托；核心仅显示，保留26个外壳碰撞体。
两种模式运行中均不重设块体位姿，也不按转层重绑定内部约束。
关节模式限制径向自由度，不模拟径向飞棱；不能再用“不脱块”单独证明正确转层。

RX自身保留八个连杆闭环 `connect`。一个外部上料 `weld` 仅在初始夹持时固定核心。
双爪建立接触后，该上料约束解除，此后不再启用。报告分别记录内部约束切换数和上料解除次数。
打开夹爪后原地回腕，没有进退避让。
动作转换复用既有规划器。报告里的 `layer_unlock`、`layer_lock` 是规划标记；在本后端分别表示开始转层和核验转层，不执行约束解锁或重绑定。
RX执行前使用十二元动作搜索，优化给定打乱或求解序列的夹爪路径。
按实际轨迹计算成本：腕轴使用轨迹时长加 `rx_wrist_settle_s`，夹爪使用 `rx_jaw_duration_s` 加 `rx_jaw_settle_s`。时间先按物理步长取整。
当前无等待实验入口见[无等待执行边界](#无等待执行边界)。
搜索不足或候选更贵时，回退到消除冗余开合后的基础计划；基础转换支持B直接转面和反面单次整块半圈换向。
每段计划起止为双爪闭合、双腕回零，段内允许保留腕角并连续转动，减少中途回腕。
当前优化固定色块移动序列，不包含旧后端的多候选求解并行搜索，不接受旧后端的速度参数。
动作搜索接入后的物理流程须单独验收，历史基础计划的完整通过记录不代表新路径也已通过。

中心轴加入固定的被动磁吸定位近似：

```text
力矩 = -A*sin(4*q) - 0.0005*v
势能 = A*(1-cos(4*q))/4
```

`q`、`v` 是实际中心轴角度与角速度，`A` 默认为0.04牛米。
每90度出现一个势能最低点。它不读取求解序列或目标角，不负责把部件吸附到槽位。
该力矩由控制循环写入 `qfrc_applied`；不是额外电机，也不是实物磁铁有限元模型。
仅在其他查看器中加载 `scene.xml` 不会执行此被动力矩或夹爪控制流程。

## 准备与运行

在仓库根目录操作。先按[首次准备](getting-started.md)安装原生依赖、EGL和录像所需的FFmpeg。
RX资产已随Git保存在 `assets/rx_gripper/`，来源与许可状态见[资产说明](../assets/rx_gripper/README.md)。

先检查指定的资产目录：

```bash
node tools/check-rx-assets.mjs
```

校验需要Node.js 18或更新版本，预期24个文件全部通过。
失败时先恢复缺失或修改的Git资产，不依赖旧输出目录。
执行单层打乱、读取物理状态、求解并还原：

```bash
./rm cube --mechanical \
  --rx-bundle assets/rx_gripper/mujoco_linkage_v5 \
  --scramble R --solve --record \
  --output output/cube-mechanical/rx-solve
```

只验证上料、夹持和承重时，将 `--scramble R --solve` 换为 `--moves ""`。
输出的 `demo.mp4` 为1倍速。仿真计算明显慢于录像长度；请观察终端打印的仿真时间。
每次验证使用新的输出目录，避免把旧报告当作本次结果。

## 关节导向实验

推荐使用 `modules/cube/configs/mechanical-rx-guided-fast.json`，显式选择 `retention_mode:1`。
它保留RX摩擦夹持，未覆盖 `rx_tip_friction`，使用默认摩擦系数1.2。
该配置使用1毫秒步长、`internal_contact_dimension:1` 和 `friction_impedance_ratio:100`。
内部外壳接触只保留法向约束，省略内部摩擦；指尖与外壳的显式摩擦接触不变。
配置使用1000毫秒动作搜索预算，最多一次重夹；过程容差为位置2毫米、角度5°、核心位移2毫米。
读取色块和最终验收仍使用下方严格标准。配置中的卡脚与底托字段在该模式下不生成相应几何。

完成上方依赖准备与资产校验后，在仓库根目录执行以下无录像短流程。
运行前确认输出目录尚不存在；已有目录时换一个新路径。

```bash
./rm cube --mechanical \
  --rx-bundle assets/rx_gripper/mujoco_linkage_v5 \
  --mechanical-config modules/cube/configs/mechanical-rx-guided-fast.json \
  --scramble "R U F2 L' D B" --solve \
  --output output/cube-mechanical/guided-fast-six-check
```

进程结束后检查 `report.json` 的 `parameters.retention_mode:1` 和 `model:experimental_joint_guided`。
退出码0、`passed:true` 与 `solved:true` 才表示本次流程通过。
还应核对逐步检查点对应实际打乱与求解序列；径向受限不代表换面时没有错层。
失败时保留报告和转动前快照，按[判据与排错](#判据与排错)定位首个偏移块。
按 `Ctrl+C` 可停止，停止后的输出可能不完整。

2026年10月11日，主线程完成 `output/cube-mechanical/guided-fast-six` 实测：

| 项目 | 结果 |
| --- | --- |
| 打乱与还原 | 6步打乱、6步求解，全部检查点通过，`passed:true`、`solved:true` |
| 仿真时间 | 56.5秒 |
| 墙钟时间 | 16.80687秒 |
| 模型几何体总数 | 513；包含视觉几何，不等于碰撞体数 |
| 最终最大位置误差 | 0.42024毫米 |
| 最终最大姿态误差 | 0.0132485弧度 |

这是一次短流程结果，不代表完整二十步或任意序列稳定。
关节导向与内部无摩擦改变了物理模型，不能把耗时差异全部归因于碰撞算法提速，也不验证径向抗脱块能力。
`mechanical-rx-guided-experimental.json` 保留内部接触维数3和0.5毫秒步长，本次六步打乱及还原也通过，计算118.05秒，最终最大位置误差0.429毫米；不能沿用快速配置的耗时。
下方模式0接触实验的历史结果同样不能移用于关节模式。

## 完整二十步实验

本节是模式0接触保持的历史实验复现入口。新关节模式入口见[关节导向实验](#关节导向实验)。

完成上述依赖准备和资产校验后，在仓库根目录执行：

```bash
./rm cube --mechanical \
  --rx-bundle assets/rx_gripper/mujoco_linkage_v5 \
  --mechanical-config modules/cube/configs/mechanical-rx-relaxed.json \
  --scramble "R U F2 L' D B R2 U' F L2 D' B2 R' U2 F' D2 L B' U R2" \
  --solve --record \
  --output output/cube-mechanical/rx-full-20-relaxed
```

该参数文件记录放宽过程容差的实验；旧基础计划已有一次完整还原，当前动作搜索路径须单独验收。
若目录已存在，先换一个新的输出路径。运行耗时可能为数小时，等待进程结束后再查看报告。
正常结束须退出码0、`report.json` 中 `passed:true` 与 `solved:true` 同时成立。
失败时保留本次报告和录像，按下方排错表检查；不要把已有录像当成成功结果。
前台运行可按 `Ctrl+C` 停止；中断录像可能不完整。

成功后可使用已纳入Git的字幕脚本，仍在仓库根目录执行：

```bash
node modules/cube/tools/annotate-mechanical-video.mjs output/cube-mechanical/rx-full-20-relaxed
```

脚本需要Node.js 18或更新版本、支持字幕滤镜的FFmpeg和 `Noto Sans CJK SC` 字体。
Ubuntu缺少字体时安装 `fonts-noto-cjk`。脚本仅接受验收成功的报告，输出1倍速 `complete.mp4`。
缺少报告、动作检查点不匹配或编码失败时停止处理，检查本次结果和依赖。

## 参数

### 软件计划预览

在仓库根目录完成原生依赖准备后，可先生成计划，不加载MuJoCo模型、不执行物理动作：

```bash
./rm cube --mechanical --plan-only --search-ms 1000 \
  --scramble "R U F2 L' D B R2 U' F L2 D' B2 R' U2 F' D2 L B' U R2" \
  --output output/cube-mechanical/plan-preview
```

查看 `plan.json` 中的 `optimization` 和 `actions`。`planning_only:true` 不表示物理验收通过。
`--plan-only` 不与 `--solve`、`--record` 同用；预览只优化给定移动序列。
`--search-ms` 设置每段搜索预算，覆盖参数文件中的 `robot_search_ms`；0只使用动作消除后的基础计划。
搜索器首次准备也可能耗时，预算不包含所有启动开销。搜索耗时不计入动作成本。
软件会核验移动等价性和原序列检查点；物理执行仍检查夹持、腕轴、碰撞和最终还原。

### 参数文件

以下参数可通过 `--mechanical-config 参数JSON` 覆盖，其他参数见[机械模型参数](mechanical-cube.md#调整参数)。

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `rx_jaw_torque_nm` | `0.3` | 每个夹爪电机的双向力矩上限 |
| `rx_jaw_duration_s` | `0.5` | 夹爪开合轨迹时间，大于0且不超过2秒 |
| `rx_jaw_settle_s` | `0.15` | 历史动作后静置时间，范围0至2秒；无等待配置为0 |
| `rx_tip_friction` | `1.2` | 指尖与外壳接触的滑动摩擦系数；设为零时同时去除该接触的扭转和滚动摩擦 |
| `rx_tip_corner_spheres` | `0` | 1将每个指垫的方块碰撞替换为四角小球；0保留原方块 |
| `rx_tip_contact_time_s` | `0.004` | 指尖与外壳接触的时间常数，范围0.001至0.1秒；较大值用于更软指垫的实验近似 |
| `rx_bearing_friction_nm` | `0.002` | 中心轴恒定摩擦阻力 |
| `rx_detent_torque_nm` | `0.04` | 被动定位力矩的峰值 |
| `turn_duration_s` | `1.5` | 手腕目标轨迹时长，含单层、整块和空腕旋转 |
| `alignment_timeout_s` | `2` | 每轮对齐确认的静置上限；0关闭等待和重夹，未对齐立即失败 |
| `alignment_regrasp_attempts` | `2` | 每个检查点最多重新夹持次数，整数0至2；0关闭重夹恢复 |
| `robot_search_ms` | `1000` | 每段固定移动序列的十二元动作搜索预算，0至60000毫秒 |
| `rx_alignment_position_m` | `0.0005` | RX动作过程中的最大块体位置误差，须大于0且小于0.005米 |
| `rx_alignment_angle_rad` | `0.02` | RX动作过程中的块体与核心角误差，须大于0且小于π/4 |
| `rx_core_position_m` | `0.001` | RX动作过程中的核心位移，须大于0且小于0.005米 |
| `cap_merge_quads` | `0` | 设为1合并共面卡脚单元的两个三角楔体；非共面单元保留原分割 |
| `cap_sectors` | `16` | 卡脚圆周分段数，取8至32之间的4的倍数；改变该值会改变几何近似 |

历史默认夹爪轨迹为0.5秒，动作后静置0.15秒；可通过上表配置。当前不沿用旧RX后端的16倍、32倍速度配置。
这些参数尚未进行实物标定。更大的夹紧力可能挤歪机构，更小的力可能在转层时打滑。
额外静置保持所有执行器目标不变，每0.05秒检查一次，连续三次达到原精度要求后继续。
该过程计入仿真时间和录像。报告的 `alignment_waits` 保留初值及全部采样。
初始已对齐时直接继续，不增加等待或辅助动作。

首轮等待失败后，仅对轻微错位尝试有界重新夹持。每次开始前须双爪闭合，另一手有双指承载接触。
全块位置误差须不超过1.5毫米，块体与核心角误差各不超过0.05弧度，核心位移不超过1毫米。
优先打开并闭合当前动作手的另一手；当前动作手不明确时先选A，第二次换手。
每次只调用原夹爪开合轨迹，不转腕、不进退、不重设位姿或内部约束。
开合前后检查支撑手接触，并保留原开口净空、闭爪接触和运行中支撑检查。
每次重夹后重新使用 `alignment_timeout_s` 上限确认，每0.05秒连续三次通过原阈值才继续。
等待期间启用禁触检查；重夹或等待异常立即停止。超过次数或不满足恢复条件仍报对齐超时。
将等待时间设为0可关闭额外等待及重夹；非零确认时间不足三个采样周期时，重夹也不能通过确认。

`report.actions` 仍只列规划动作。实际辅助开合另存 `alignment_regrasps`，
包含每次恢复及各开合动作的起止仿真时间、初末位姿、完成状态和恢复结果。
等待与开合期间的 `current_action` 分别标为 `alignment_wait` 和 `jaw`，
避免将辅助阶段接触力计入转腕峰值；成功后恢复原动作，异常保留失败阶段。

## 判据与排错

成功须同时满足进程退出码0和 `report.json` 中的 `passed:true`；要求还原时还须 `solved:true`。
报告中的 `fixed_core_test_rig:false` 表示自由核心模式，`actuators:4` 表示仅有四个RX电机。
`equalities:9` 包含八个RX闭环和已解除的上料约束，不表示魔方内部有九个锁定约束。

检查 `jaw_checks` 中双指法向力、开口宽度，以及 `steps` 中的内部位姿和核心误差。
`peak_turn_tip_contact_tangent_n` 记录转腕期间采样到的指尖切向接触力峰值，用于检查摩擦传力。
过程检查默认限制内部位置误差0.5毫米、姿态误差0.02弧度、核心平移1毫米。
可用上述三个参数放宽过程检查；闭合夹爪两侧仍须有承载接触。
打乱结束读取色块前及最终检查，仍使用位置0.5毫米、姿态0.02弧度、核心平移1毫米的验收标准。
打乱结束读取色块前及最终检查，还要求棱角块的最大单坐标位置误差不超过块间距的2%，约0.367毫米。
字段为 `facelet_position_component_error_m`，不统计中心块，与色块读取器的部件范围一致。
原全块位置范数、姿态及核心条件继续生效，物理色块读取器本身的严格条件不变。
该准备检查也可触发上述等待与有界重夹，不能用四舍五入掩盖错位。

腕轴跟踪误差阈值为0.006弧度；开爪净空须大于55毫米乘以根号2，再加1毫米。

长序列放宽实验使用块体位置2毫米、块体与核心角度5°、核心位移2毫米，并关闭自动重夹。
这些值是实验容差，尚未证明长序列可完成；不放宽脱块、失去支撑及数值异常检查。

| 报错 | 处理 |
| --- | --- |
| `RX lost cube support` | 已检测到核心明显掉落；保存滑落图和报告，检查夹紧力与指尖接触 |
| `RX mechanical pose mismatch` | 内部错位或转层未完成；保留当前参数，定位最先偏移的部件 |
| `RX core slipped` | 整块位置或朝向不符合预期；检查摩擦和换手承重 |
| `RX jaw contact/clearance failed` | 闭爪未形成双边接触，或开爪不足以原地回腕 |
| `RX forbidden rotation contact` | 回腕触碰魔方或两只夹爪发生承载碰撞 |
| `RX alignment timeout` | 有界等待与允许的重夹后仍未达到原精度；检查 `alignment_waits`、`alignment_regrasps` 和换手受力 |

过程容差实验须记录实际参数；不能修改已失败报告、重新开启上料固定或重设位姿来宣称成功。
旧RX后端的长序列通过记录不能代表这个连续接触模型已通过。

## 单步故障复现

程序在每次转腕前将积分状态保存到输出目录的 `diagnostic_states/`。
快照只读取仿真状态，不改变执行过程。文件中的 `action` 标明待执行动作。
`before_` 快照位于精度检查前；若发生额外静置，另存 `aligned_` 快照表示实际转动前状态。
报告增加 `before` 转层前检查和 `whole` 换向后观测；单手换向后尚未重新夹紧，
`whole` 只记录瞬态偏差，转层前和原有检查点仍使用完整验收阈值。

在仓库根目录构建独立复现工具：

```bash
TMPDIR="$PWD/.cache/tmp" cmake --build build --target rm_cube_mechanical_replay -j4
build/bin/rm_cube_mechanical_replay \
  output/cube-mechanical/rx-solve/scene.xml \
  output/cube-mechanical/rx-solve/diagnostic_states/before_3.json \
  output/cube-mechanical/replay
```

按实际输出替换场景和快照路径。两者必须来自同一次运行。
工具在独立进程初始化时恢复快照，执行一次转腕或开合，输出接触力轨迹、误差报告和末帧。
开合诊断的规划目标使用0或115，按实际轨迹显式覆盖 `turn_duration_s:0.5`。
输出的 `end_state.json` 仅供后续独立诊断，不能作为连续录像的续录点。
`pose_passed` 只评价末态位姿，不代替主流程的腕角、夹持和禁触验收，也不运行自动对齐等待。
`dynamics_wall_time_s` 包含控制推进、接触检查、轨迹记录及末态 `mj_forward`，不含加载、报告写盘和末帧渲染。
`timers` 记录MuJoCo各阶段累计毫秒数；各层计时嵌套，不能全部相加。
可追加参数JSON，单独比较转腕时长、步长、夹爪力矩或被动定位力矩。

## 接触稳定性对照参数

以下参数用于实验，不替换已验证的完整录像配置。保持原质量、力矩和验收标准。
在仓库根目录使用前述批量复测工具；每项须保留完整参数和失败报告。

| 参数 | 含义与默认值 |
| --- | --- |
| `rx_tip_sphere_radius_m` | 小球半径，默认0.003米，允许0.0005～0.003米 |
| `rx_tip_sphere_offset_m` | 四角中心在面内的正负偏移，默认0.005米；不小于半径，与半径之和不超过0.008米 |
| `ball_damping_nm_s` | 20个导向球关节的阻尼，默认0.00002牛米秒/弧度；不修改RX连杆或中心轴阻尼 |
| `rx_wrist_zero_jerk` | 默认0；设为1使用端点加加速度为零的七次腕轴曲线，同时更新规划时长，夹爪曲线保持不变 |
| `cube_magnet_peak_force_n` | 实验性棱角磁吸单对峰值力，默认0关闭，允许0～2牛；不改变关节与碰撞结构 |

球半径变化时，球心沿接触法线移动，保持原最内侧接触平面和净空包络。
七次曲线仍受速度和加速度上限约束，但时长通常增加，不能将效果全部归因于曲线平滑。
腕速设为0的旧固定时长模式不自动约束速度与加速度。

磁吸结构参考[GAN356 M 厂家说明](https://www.gancube.cn/en/gan356m/)中的48颗磁铁。
角块各3个磁吸点，棱块各2个；两侧各埋深1.5毫米，以6毫米范围的光滑径向势能近似吸力。
力的大小由当前距离计算，成对等大反向；不读取颜色、目标排列或求解动作。
强度、埋深和力曲线没有实测标定，不能据此声称复现某款实物魔方。
中心轴原有被动定位力矩仍单独保留。实验结果须区分两种回正机制。

四角小球与0.3牛棱角磁吸已取得一条完整20步录像；同参数另外两条序列失败，仍为实验配置。
完整视频、参数和报告见[仓库资产](../assets/mechanical_cube/README.md#四角小球与棱角磁吸对照)。
复现前须完成本页RX资产准备与构建，在仓库根目录运行；新输出目录不得复用历史结果。

```bash
./rm cube --mechanical --rx-bundle assets/rx_gripper/mujoco_linkage_v5 \
  --mechanical-config assets/mechanical_cube/corner_magnets_20_parameters.json \
  --scramble "R U F2 L' D B R2 U' F L2 D' B2 R' U2 F' D2 L B' U R2" \
  --solve --record --output output/cube-mechanical/corner-magnets-recording
```

命令结束后检查 `report.json` 的 `passed` 与 `solved` 均为 `true`，再查看 `demo.mp4`。
失败时保留报告与诊断快照，按本页故障处理定位首次异常，不将失败录像标为完整还原。

磁吸的单块自由度不能只按磁势能判断稳定性。对当前0.65毫米倒角场景，120项单块扰动中有48项磁势能下降。
扰动0.01弧度时这些方向均导致外壳穿透，最深约0.218毫米；扰动0.001弧度时仍有负刚度，但保留约0.023毫米间隙。
这表示磁吸可把块推向接触面，后续必须由实体接触承载。六个合法整层转动的端点均有恢复力矩。
0.1度间隔的六层扫描未发现额外势能井，单对0.3牛时峰值层磁力矩约0.01514牛米。
这些静态检查不能代替完整动力学验收。原始数据见 `assets/mechanical_cube/magnet_local_stability.tsv`。

完成C++构建后，可在仓库根目录对已生成场景复测静态诊断：

```bash
cmake --build build --target rm_cube_magnet_stability
build/bin/rm_cube_magnet_stability \
  output/cube-mechanical/corner-magnets-recording/scene.xml \
  > output/cube-mechanical/corner-magnets-recording/magnet-stability.tsv
```

输出按扰动方向记录势能、虚功、接触穿透和几何最近距离。缺少场景时先完成前述录像命令。

`tip_torsional_friction_m` 控制单个指尖接触的等效扭转摩擦半径，默认0.002米，允许0～0.01米。
设为0时使用三维接触，仅保留法向和两个切向；多个接触点仍可通过力臂传递扭矩。
非零时保留第四维扭转摩擦。该选项用于比较方形接触面和四球近似，不代表橡胶接触斑的实测尺寸。
