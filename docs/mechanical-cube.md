# 魔方连续接触机构原型

## 当前能力与边界

入口为 `./rm cube --mechanical`。模型名义边长55毫米，由程序生成球芯、卡脚、颈部和倒角外壳。
该入口使用固定核心和六个中心轴执行器，验证魔方内部的接触传力与保持能力。
它尚未接入RX夹爪，不支持 `--dual`、`--viewer` 或 `--rpc`。
旧RX模型的16倍腕速和32倍开合参数不适用于该试验台。

| 部件 | 坐标与连接 | 保持方式 |
| --- | --- | --- |
| 核心 | 固定球芯 | 作为机构试验台的基座 |
| 六个中心块 | 每块一个转轴、一个有限行程的轴向滑动关节 | 轴向弹簧预紧，中心卡脚带四个缺口和对角承托翼 |
| 十二个棱块 | 每块一个六自由度 `freejoint` | 卡脚、球面底托与相邻部件接触 |
| 八个角块 | 每块一个六自由度 `freejoint` | 下层球面卡脚、颈部及相邻部件接触 |

`freejoint` 是刚体坐标表示，部件的可达位置由实体接触限制。
装配保持不依赖色块焊接、球铰保持或固定球面距离约束。
模型的 `equality` 数量为零。动力学执行不重设 `qpos`、`qvel`，不切换或重写约束。
逻辑槽位仅用于结果核验，不用于驱动或修正部件。

这里的机械闭合通过接触形成。它不是把相邻色块永久连接成一个转轴环。
MuJoCo的刚体树与接触系统共同表示该机构，见[官方建模说明](https://mujoco.readthedocs.io/en/stable/modeling.html)。
卡脚分解为多个凸楔体，保留内侧空腔；凹形网格的碰撞处理边界见[官方碰撞说明](https://mujoco.readthedocs.io/en/stable/computation.html#collision-detection)。
中心翼、棱块凸缘和角块连接部的相互保持可参考[魔方机构专利中的结构说明](https://patents.google.com/patent/US10583351B2/en)。本模型尺寸为自定义参数，不是该专利或某款实物的尺寸复刻。

## 准备与运行

以下命令在仓库根目录执行。首次使用先按[准备说明](getting-started.md)安装原生依赖并运行 `./rm setup`。
图像渲染需要EGL；录像还需要FFmpeg。无窗口模式不需要DISPLAY。
该模式不需要用户提供RX压缩包，也不调用运行时Python。

打乱三步，从实际部件位姿读取状态，再调用Kociemba求解并执行：

```bash
./rm cube --mechanical --scramble "R U F" --solve --record \
  --output output/cube-mechanical/demo
```

`--record` 保存1倍速、30帧每秒的视频。去掉它可停止录像，但仍生成初始、内部和结束图像。
该模型包含大量凸碰撞体，仿真墙钟时间明显长于视频；短序列可能需要数分钟。
终端会打印仿真时间和接触数。中途停止使用 `Ctrl+C`，此时文件可能不完整。
每次复验换一个输出目录，避免用旧报告判断新运行。

手动执行跨轴正反序列：

```bash
./rm cube --mechanical --moves "R U F F' U' R'" \
  --output output/cube-mechanical/manual
```

支持 `R/L/U/D/F/B` 及逆转、半圈记号。`--moves` 与 `--scramble` 是同一序列参数。
没有 `--solve` 时只执行指定序列，不要求最终处于还原状态。
`--help` 显示该模式接受的参数；不支持的旧模式参数会被拒绝。

## 输出与成功判据

输出目录包含：

- `scene.xml`：本次生成的完整碰撞模型。
- `initial.png`、`internal.png`、`step_N.png`、`final.png`：外观、内部结构和动作检查点。
- `demo.mp4`：指定录像时生成的实时速度视频。
- `report.json`：参数、每步实际误差、实测色块状态、求解结果和最终状态。

本次进程须以退出码0结束，且报告中 `passed:true`。
带 `--solve` 的运行还须满足 `solved:true`，实际读取的54面贴状态为还原状态。
中心块允许弹簧轴向位移；每步最大位置误差须不超过0.5毫米，姿态误差须不超过0.02弧度。
色块读取另要求归一化位置与旋转矩阵元素接近整数，容差为0.02。
出现数值警告、径向脱出、转层未到位或色块读取不对齐时，程序返回非零退出码。
阶段失败后保留已有图像和报告，不会吸附回合法状态继续执行。

`fixed_core_test_rig:true` 和六个中心执行器是当前试验条件。
不能把该报告当作RX摩擦夹持、自由核心或实物硬件已经通过的证据。

## 调整参数

创建JSON参数文件，再用 `--mechanical-config 文件路径` 传入。只需填写要覆盖的字段。
实际生效的全部字段写入报告的 `parameters`。

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `shell_gap_m` | `0.00005` | 相邻外壳的名义间隙 |
| `shell_bevel_m` | `0.00065` | 外壳倒角尺度 |
| `cap_inner_m` | `[0.0146,0.01265,0.01085]` | 中心、棱、角卡脚的内半径 |
| `cap_outer_m` | `[0.0162,0.0143,0.0125]` | 三类卡脚的外半径 |
| `cap_angle_deg` | `[43,21.5,31]` | 三类卡脚的最大角度范围；中心另保留颈部缺口 |
| `preload_stiffness_n_m` | `500` | 中心轴向弹簧刚度 |
| `preload_reference_m` | `-0.0015` | 弹簧参考位移；轴向行程为正负1.5毫米 |
| `turn_duration_s` | `1.5` | 一步转动的目标斜坡时长；随后等待0.3秒 |
| `timestep_s` | `0.0005` | 物理步长 |
| `max_torque_nm` | `0.03` | 每个中心轴执行器的力矩上限 |
| `record_fps` | `0` | 0表示不录像；1至60的整数启用录像；`--record` 将其设为30 |

接触摩擦、刚体惯量和接触软化仍是简化参数。
改变卡脚、间隙或预紧后，须重新完成几何扫描和动力学测试；参数能够解析不表示机构可运行。

## 独立几何扫描

先完成 `./rm build`，再显式构建扫描程序：

```bash
mkdir -p .cache/tmp
TMPDIR="$PWD/.cache/tmp" cmake --build build --target rm_cube_mechanical_sweep -j4
build/bin/rm_cube_mechanical_sweep \
  output/cube-mechanical/demo/scene.xml \
  output/cube-mechanical/demo/sweep.json
```

程序对六个面分别从负180度到正180度按5度采样，共438个构型。
它会在独立诊断进程中设置构型并检查碰撞，不执行动力学。
输出标记为 `mode:geometry_only`；扫描通过不能代替接触转动、预紧或脱块验收。
阈值为20微米穿透，超限返回非零退出码。

## 本次验证结果

2026年10月9日，使用默认几何和参数完成以下物理验证：

| 场景 | 结果 |
| --- | --- |
| 打乱 `R U F`，读取物理状态并求解 | 执行 `F' U' R'` 后还原 |
| 打乱 `L D B`，读取物理状态并求解 | 执行 `B' D' L'` 后还原 |
| 跨轴半圈 `R2 U2 F2 F2 U2 R2` | 六步完成后还原 |
| 六面共438个离散构型的几何扫描 | 未检测到穿透 |
| 驱动力矩降低到 `1e-9` 牛米，执行 `R` | 正确报告转层不到位，退出码1 |
| 参数错误、非法动作、报告文件无法写入 | 返回非零退出码 |

三组成功序列的逐步最大位置误差约0.264毫米，姿态误差约0.53度。
本次 `./rm test` 通过20项C++测试、19项Rust测试和34项Node测试；文档检查通过57个文件。
原有魔方录像入口另行通过960×720、30帧每秒的视频检查。
这些是短序列的试验结果，尚不代表长随机序列、自由核心或夹爪驱动已通过。
报告及录像保存于 `output/cube-mechanical/`，不随源码提交。

## 失败处理

| 现象 | 处理 |
| --- | --- |
| 初始化即散开或脱块 | 保存 `report.json`；核对卡脚半径、间隙、预紧与接触参数 |
| 转动中卡住 | 先跑几何扫描定位部件对，再检查动态错位；不提高误差阈值掩盖失败 |
| `Physical pieces not aligned` | 保存最后一张检查点图和报告，不把未对齐状态送入求解器 |
| EGL或FFmpeg失败 | 按[渲染与录像排错](troubleshooting.md)修复依赖，再使用新输出目录重跑 |
| 想用RX或交互窗口 | 当前仍是固定核心试验台；RX接入须另行完成核心自由度、夹持和转层验收 |
